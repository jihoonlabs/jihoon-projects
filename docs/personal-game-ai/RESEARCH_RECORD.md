## 결과·계약
research_record.py가 game_brief 기획과 같은 기기의 조사 자료를 새 JSON에 연결한다. gameplay/hardware 분류, 주제·결과·출처·확인일·documented/measured/unknown 상태를 검증한다. 문서 확인은 HTTP(S) URL, 실측은 측정 기록 참조, 미확인은 빈 출처를 허용한다.
자료는 검토자가 제공하며 URL 접근·자료 사실 확인·측정 파일 존재 확인을 자동 수행하지 않는다. 날짜는 형식만 확인한다. 조사 기록의 출처 표기는 정확성 보장이 아니다.
입력·정책·명세 미승인 상태를 검사하고, 다른 기기 자료와 기존 출력 덮어쓰기를 거부한다. 입력 원본을 변경하지 않는다. 같은 기기의 조사 항목을 새 목록으로 교체하는 명시적 snapshot이며 이전 파일은 보존한다.

입력·조사·기존 연결 관련 46개 검사 통과. unknown 유지, 기기 혼용 차단, 근거 형식, 승인·정책 보호, CLI 원본 보존을 확인했다. Ollama·Docker·실기 검증 없음. 기존 engine·게임·승인 기록 변경 없음.
자동 조사·축소안 생성·선택·명세 승인은 미구현이다. 다음 책임은 근거를 검토한 축소 선택지와 사용자 결정 기록이다. 사용자가 실제 화면·조작·속도를 확인하여 확정한 기본값은 후속 단계에서 별도 기록하고 재사용한다. 조사만으로 기본값이나 명세 승인을 확정하지 않는다.
commit·일반 push 허용, merge 금지. 현재 조사 결과를 workflow 생성 요청으로 넘기지 않는다.
