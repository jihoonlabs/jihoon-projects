## 목표·규칙
- 작업 목록에서 파일 수정과 고정 테스트를 실행한다.
- 지침은 AGENTS.md와 이 문서만 읽는다.
- 같은 폴더에서 브랜치를 전환하며 새 worktree는 만들지 않는다.
- 기존 변경·untracked·stash를 보존한다.
- Git 작업은 사용자가 수행하고, 검증 후 Epic에 통합한다.

## 구현
- kind: edit에 target·prompt·test_module을 지정한다.
- 대상과 테스트는 sandbox 바로 아래의 Git 추적 Python 파일로 제한한다.
- 대상·테스트의 기존 Git 변경, 잘못된 경로, 심볼릭 링크를 차단한다.
- 고정 Docker 테스트로 최대 3회 수정·재검사한다.
- 통과·질문·실패를 저장한다.
- 질문·중단 작업이 있거나 수정 작업이 실패하면 목록을 멈춘다.
- 두 실행기에 잠금과 실행 중 외부 변경 검사를 적용한다.
- 원본·응답·수정 후보·검사 로그·결과를 저장한다.
- 기존 text·python 처리와 runner_tasks.json을 유지한다.
