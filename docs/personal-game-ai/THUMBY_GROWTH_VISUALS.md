# ThumbyGrowth 배경과 다음 개선

## 현재 범위
일반 흑백 Thumby의 72×40 화면에서 현재 15전투 게임의 장소와 이동을 알아볼 수 있게 한다.
기존 Epic에서 작업하고 새 브랜치/worktree를 만들지 않는다.
실기 확인을 기다리는 동안 할 수 있는 코드·화면·검증 작업을 진행한다.

## 목표와 현재 지역 구성
최종 목표는 쿠니오군 시대극 같은 횡이동 액션 RPG 시스템을 일반 Thumby에서 최대한 구현하는 것이다.
한국 5·중국 5·일본 5의 중세풍 허구 무대다. 역사적 건축의 정확한 복원은 아니다.
현재는 15개의 배경과 1대1 전투 진행을 연결한 초안이며 지역 지도나 군중 난투가 완성된 상태가 아니다.

| 구간 | 한국 KR1–5 | 중국 CN1–5 | 일본 JP1–5 |
| --- | --- | --- | --- |
| 1 | 기와 읍성길 | 성곽 대로 | 산촌길 |
| 2 | 대나무 고개 | 강가 나루 | 소나무 고개 |
| 3 | 산성 돌길 | 대숲 | 해자 석교 |
| 4 | 사찰 마당 | 층탑 마당 | 성하 마을 |
| 5 | 산성 누각 | 성채 중정 | 성곽 본진 |

현재 코드의 진행 순서는 KR1–5 → CN1–5 → JP1–5다.
각 지역 5번째 전투의 적 능력치를 높였고, 마지막 JP5 이후에만 엔딩이 나온다.
중간 지역 전환에서 돈·장비·저장을 초기화하지 않는다.
옛 5전투 완료 저장 progress=5는 CN1에서 계속된다. 저장 스키마 version=1은 유지한다.

- 먼 배경은 camera//3, 바닥 표식은 실제 camera 속도로 움직인다.
- y=0..13 HUD를 침범하지 않고 모든 사각형을 72×40 안으로 잘라 그린다.
- 캐릭터/적 뒤에 검은 1픽셀 여백을 그려 흰 배경과 분리한다.
- 배경은 장식이다. 기둥·철창을 충돌 장애물이나 숨은 기능으로 취급하지 않는다.
- 전투 규칙, 충돌 6×7, 이동 범위, 구매/장착, 저장 version=1은 변경하지 않는다.
- 일반 drawFilledRectangle만 사용하며 신규 기기 API나 의존 모듈을 추가하지 않는다.
- 도형 목록은 한 번 정의한다. 테스트 표본의 전체 프레임 사각형 호출은 160회 이하로 제한한다.

## 검증
- 게임 검사 59개 통과: 기존 게임/완료 검사와 배경 6개, 지역 전환/이전 저장 검사 2개.
- 배경 검사: 15종 구분, 반복 렌더 동일성, camera=0..72 모든 위치의 경계,
  스크롤 변화, 캐릭터 여백/레이어 순서, 상태 불변, 호출 수 상한.
- 실제 게임 코드로 화면 미리보기를 렌더링했다. 미리보기 글꼴은 모의 5×7 글꼴이다.
- 실제 Thumby·에뮬레이터의 FPS, 메모리, 밝기/가독성, 조작감은 미검증이다.

## 시스템 확장 우선순위
현재 적용한 단계와 목표 시스템을 구분한다.

| 시스템 | 현재 | 다음 범위 |
| --- | --- | --- |
| 상하좌우 바닥 이동·방향 공격 | 구현 | 타격 반응/경직과 공격 전조 |
| 돈·구매·장착·능력치·저장 | 구현 | 지역 상점/성장 선택 확장 |
| 지역 진행·지역별 배경·보스 능력치 | 15전투 초안 구현 | 짧은 이동 구간, 출구, 마을 연결 |
| 점프·잡기·던지기 | 미구현 | 작은 캐릭터 상태 계약부터 단계적으로 추가 |
| 복수 적·무기 줍기·특수 기술 | 미구현 | 동시에 관리할 적 수를 제한한 난투 구조 |

다음 구현은 먼저 현재 기기/에뮬레이터의 재현 가능한 문제와 타격 표현을 고친다.
그 뒤 점프/잡기/던지기와 복수 적을 작은 계약/검사로 연결한다.
배경 15개를 그렸다는 이유로 쿠니오군 시스템 구현 완료라고 판단하지 않는다.
게임의 코드·그림·등장인물은 직접 만들고 원작 자산은 가져오지 않는다.

권리자 공개 자료의 원작 식별 참고:
[Technos 공식 아카이브](https://www.arcsystemworks.jp/technos/archive/).
기술적 저해상도 구현 참고는 위 일반 Thumby 게임 4개이며, 원작 전체 기능에 대한 분석을 마쳤다는 의미는 아니다.

실제 게임 하나를 먼저 만들고, 검증된 코드·실패/수정 경험을 집의 Ollama와 외부의 ChatGPT가 같은 Git에서 이어받는다.
파인튜닝, 새 엔진, Color 이식, 무분별한 브랜치 확장을 현재 게임보다 앞세우지 않는다.
