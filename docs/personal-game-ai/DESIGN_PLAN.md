# 개인 게임 AI — 설계 제안 Child

갱신일: 2026-10-03
브랜치: feature/personal-game-ai-design-plan

## 목표·규칙
- 목표에서 파일 구성·함수 계약·검사 조건을 로컬 AI가 제안한다.
- 사용자는 목표와 중요한 분기를 결정한다.
- 지침은 AGENTS.md와 이 문서만 사용한다. AGENTS.md 수정 금지.
- 같은 작업 폴더를 사용하고 worktree를 생성하지 않는다.
- 기존 untracked·stash·runner_tasks.json을 보존한다.
- 수정본은 파일 전체, 개인 AI 문서는 한국어로 제공한다.
- 외부 유료 API와 공개 push는 사용하지 않는다.
- commit·merge는 승인 범위 안에서 수행한다.
- main 통합·브랜치 삭제는 하지 않는다.
- 게임 그래픽 작업은 중단했다.

## 설계 계약
- 입력은 목표·필수 조건·허용 작업 영역이다.
- 필수 조건은 사용자가 지정하고 모델이 삭제하거나 변경하지 못한다.
- 모델은 파일명·함수 인자·동작·검사 사례·의존성을 제안한다.
- 각 검사 사례는 어떤 필수 조건을 확인하는지 표시한다.
- 허용 영역 바로 아래의 새 Python 파일만 제안한다.
- 기존 파일 덮어쓰기·테스트 실행·게임 파일 생성은 수행하지 않는다.
- 경로·중복·검사 연결·의존성 구조와 분량을 검사한다.
- 설계와 원래 입력은 outputs에 새로 저장한다.
- SHA-256으로 검토한 설계 버전에 대한 승인 기록을 남긴다.
- 승인은 설계 생성 당시 문맥과 현재 문맥이 일치할 때만 허용한다.
- 설계 승인만으로 구현이나 테스트 생성을 실행하지 않는다.
- 승인 설계의 고정 테스트 준비 후 기존 구현 계획에 연결한다.

## 검토 의견 기반 수정 계약
- --revise 기존설계 --feedback 의견파일로 모델에 수정을 요청한다.
- 원래 목표·필수 조건·허용 영역은 유지한다.
- 이전 설계와 검토 의견을 모델에 함께 전달한다.
- 사람이 설계 JSON을 직접 수정하지 않는다.
- 원본을 덮어쓰지 않고 새 outputs/design_* 폴더에 저장한다.
- 원본 경로·SHA-256·검토 의견을 revision.json과 새 설계에 기록한다.
- 생성 실패 시에도 원래 입력·검토 의견·응답 기록을 보존한다.
- 이전 설계와 문맥이 달라도 현재 지침으로 새 설계를 제안할 수 있다.
- 생성 도중 문맥·작업 영역·원본 설계 변경을 발견하면 중단한다.
- 기존 승인 기록은 보존하며 새 설계에 승인을 승계하지 않는다.
- 구조 검사 실패 시 최대 3회 시도한다.
- 구조 검사만으로 의미상 정확성이나 검사 충분성을 보장하지 않는다.
