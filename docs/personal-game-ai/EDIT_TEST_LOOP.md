## 범위와 확정 사항
- My PRJ/ai/personal-game-ai 안에서 개발한다.
- 새 worktree를 만들지 않는다.
- 지침은 AGENTS.md와 이 문서만 읽는다.
- 기존 요청 함수와 문맥 검증 코드를 재사용한다.
- 첫 검증은 별도 시험용 Python 파일과 고정 테스트로 수행한다.
- 기존 게임·포트폴리오·시험 결과 파일은 수정하지 않는다.
- 이번 실행기의 수정 대상은 sandbox/clamp.py 하나로 고정한다.
- 테스트 명령은 사용자가 지정하며 모델이 변경하지 못한다.
- 테스트 파일은 모델 수정 대상에 포함하지 않는다.
- 최초 생성을 포함해 최대 3회 수정 시도한다.
- 새 설계 결정이 필요하면 질문을 저장하고 중단한다.
- 브랜치 불일치는 수정 전에 중단한다.
- 실행 중 수정 대상·고정 테스트·지정 문맥의 변경을 감지하면 중단한다.
- 실행 전 Git 변경 상태를 검사하는 기능은 아직 미구현이다.
- 수정 전 원본을 보관하고 시도별 응답·변경·검사 결과를 기록한다.
- Git commit·merge·push는 자동 수행하지 않는다.

## 현재 상태와 검증
- 시험용 sandbox/clamp.py 하나의 자동 수정 흐름을 구현했다.
- 원본·모델 응답·수정 후보·Docker 검사 로그를 저장한다.
- 최대 3회 시도하며 사용자 질문이 나오면 중단한다.
- 동시 실행 잠금과 실행 중 외부 변경 감지를 구현했다.
- 모델 대역 테스트 8개 통과.
- 실제 Ollama가 첫 시도에 함수를 수정하고 Docker 테스트 7개 통과.
- 실제 모델의 실패 후 재수정과 질문 흐름은 미검증이다.

## 실행 범위와 제한
- Docker에서 네트워크 차단·읽기 전용 마운트·자원 제한으로 검사한다.
- 모델은 고정 테스트 파일을 수정하지 않는다.
- 현재 대상 파일과 테스트 명령은 실행기에 고정돼 있다.
- 테스트 통과는 지정한 검사 범위의 정확성만 의미한다.
- 게임 전체 개발과 장시간 무인 실행은 아직 검증하지 않았다.
- 실행 전 Git 변경 상태 검사와 작업 목록 연결은 미구현이다.
