## 승인한 범위
- 목표·필수 조건·함수 계약·검사 사례에서 unittest 후보를 생성한다.
- 응답 형식·파일명·Python 구문과 테스트 구조를 검사한다.
- 기존 파일을 변경하지 않고 outputs의 새 폴더에 후보와 기록을 저장한다.
- 구조 오류 피드백으로 최대 3회 시도한다.
- 검토한 후보의 SHA-256을 확인해 확정 기록을 생성한다.
- 테스트 설치·Git 등록·구현 생성·후보 코드 실행은 이번 범위 밖이다.
- 구조 검사만으로 테스트의 정확성·충분성·안전성을 보장하지 않는다.
