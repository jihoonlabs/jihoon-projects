## 목표·규칙
- 로컬 Ollama로 승인된 게임 개발 작업을 수행하고 중요한 결정은 질문한다.
- 최종 목표는 작업 분할·파일 생성·구현·검사를 이어가는 자동화다.
- 외부 유료 API는 사용하지 않는다.
- main → Epic → Child. 검증한 Child를 Epic에 통합한다.
- 같은 My PRJ 폴더를 사용하며 새 worktree는 만들지 않는다.
- 코드: ai/personal-game-ai/. 문서: docs/personal-game-ai/.
- 지침은 AGENTS.md와 현재 브랜치 MD 하나만 사용한다.
- AGENTS.md 수정 금지. 수정본은 파일 전체, 개인 AI 문서는 한국어로 제공한다.
- 기존 untracked 5개·stash 1개·작업 목록을 보존한다.
- commit·push·merge는 승인 범위 안에서 수행한다.
- main 통합·완료 Child 삭제는 하지 않는다.

## 현재 기능
- text: 응답 저장. python: 코드 저장·문법 검사. edit: 수정·Docker 검사.
- 수정은 최대 3회 시도하며 실패 로그를 모델에 전달한다.
- 고정 테스트·Docker 명령 보호, 실행 잠금·외부 변경 검사를 적용한다.
- Docker는 네트워크 차단·읽기 전용 마운트·자원 제한을 사용한다.
- 질문 시 원본 복원, --answer 작업ID로 누적 답변 저장·재개를 지원한다.
- 질문·중단·수정 실패 시 목록을 멈춘다. 성공하면 후속 작업을 진행한다.
- sandbox 동작을 유지하며 game/파일.py를 edit_directory 설정에 연결한다.
- 게임 폴더는 저장소 내부로 제한하고 경로 이탈·심볼릭 링크를 차단한다.
- 수정 대상·테스트는 Git 추적 상태이며 기존 변경이 없어야 한다.
- 현재 Epic 설정은 게임 폴더를 지정하지 않는다.
