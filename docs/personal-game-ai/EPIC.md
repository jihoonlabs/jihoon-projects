## 현재 기능
- text: 응답 저장. python: 코드 저장·문법 검사. edit: 수정·Docker 검사.
- edit 작업에 target·prompt·test_module을 지정한다.
- 대상·테스트는 sandbox 바로 아래의 Git 추적 Python 파일로 제한한다.
- 대상·테스트의 기존 Git 변경, 잘못된 경로, 심볼릭 링크를 차단한다.
- 고정 테스트와 Docker 명령은 모델이 변경하지 않는다.
- Docker에 네트워크 차단·읽기 전용 마운트·자원 제한을 적용한다.
- 실행마다 최대 3회 수정하며 질문·중단 작업·수정 실패 시 목록을 멈춘다.
- 두 실행기에 잠금·외부 변경 검사를 적용하고 원본·시도·결과를 저장한다.
- 질문 시 외부 변경을 검사한 뒤 수정 대상을 실행 전 원본으로 복원한다.
- --answer 작업ID로 답변을 입력받고 누적 질문·답변을 저장한다.
- 재개 시 원래 요청과 질문·답변을 전달하고 기존 검사·수정 과정을 실행한다.
- 수정 성공 후 후속 작업을 진행하며 다른 미해결 질문이 있으면 멈춘다.
- running 작업이 있으면 답변 저장과 실행을 멈춘다.
- validate_model.py는 outputs의 복사본으로 실제 모델을 검증한다.
- 모델: qwen3-coder:30b. Docker 이미지: python:3.11-slim.

## 검증·제한
- 질문 후 재개 Child에서 회귀 테스트 54개·설정 검사·diff 검사 통과.
- Epic 통합 후에도 회귀 테스트 54개·설정·브랜치·경로 검사·git diff --check 통과.
- 실제 모델에 오류를 유도한 뒤 Docker 실패 로그로 재수정해 7개 테스트 통과.
- 실제 모델 질문·중단 후 답변 저장·재개·Docker 검사·후속 작업 진행 확인.
- 검증 중 원본 코드·고정 테스트·기존 작업 목록 보존 확인.
- 수정 실패 후 질문 시 원본 복원과 외부 변경 보존은 모의 테스트로 확인.
- CLI의 대화형 답변 입력은 아직 직접 검증하지 않았다.
- 자연 발생 실패 후 재수정과 자발적인 중요 결정 식별은 미검증.
- 장시간 무인 실행·게임 전체 자율 제작·실기 실행은 미검증.
- 작업 의존성 관리·running 및 failed 복구·Git 자동화는 미구현.
- failed 작업은 자동 재실행하지 않으며 다음 실행 전체를 차단하지도 않는다.
- Git 변경 검사는 대상·고정 테스트에 한정한다.
- 수정 요청은 누적 질문·답변을 포함해 4000자로 제한한다.
- 전체 요청·응답 분량 제한과 일부 실패 경로 검증은 미완료.
- 테스트 통과는 지정한 검사 범위만 보장한다.
- Thumby·Thumby Color·스타크래프트 유즈맵의 실제 제작 환경 연결은 미구현.
