## 현재 기능
- text: 응답 저장. python: 코드 저장·문법 검사.
- edit: 기존 Python 파일 수정. create: 없는 Python 파일 하나 생성.
- 문법·고정 Docker 검사와 최대 3회 재수정을 지원한다.
- 실행 잠금·외부 변경 검사·고정 테스트 보호를 적용한다.
- Docker는 네트워크 차단·읽기 전용 마운트·자원 제한을 사용한다.
- 질문·답변 누적 저장과 답변 후 재개를 지원한다.
- 파일 작업의 질문·중단·실패 시 목록을 멈추고 성공 시 다음 작업을 진행한다.
- edit는 대상·테스트의 Git 추적과 기존 변경 없는 상태를 요구한다.
- create는 대상 부재와 고정 테스트의 Git 추적·변경 없는 상태를 요구한다.
- create의 질문·최종 실패·처리 가능한 오류에서는 이번 생성 파일만 정리한다.
- 외부 변경이 있으면 보존하고 중단한다. 후보·로그는 outputs에 남긴다.

## 작업 계획
- 작업 계획 Child를 3c96f5a에서 통합했다.
- plan_tasks.py는 승인된 목표와 허용 대상을 받아 작업 요청을 나눈다.
- 대상·작업 종류·고정 테스트는 사람이 지정한다.
- edit/create만 허용하며 대상마다 작업 하나로 제한한다.
- 구조·중복·요청 길이·경로·Git 상태와 계획 생성 중 외부 변경을 검사한다.
- 원래 목표를 각 요청에 포함하고 계획 형식 오류는 최대 3회 재시도한다.
- 새 계획은 outputs/plan_*/tasks.json에 저장한다.
- execute_plan.py는 별도 계획을 기존 실행기로 처리하고 failed 작업이 있으면 차단한다.

## 게임 연결
- 도구 개발과 플랫폼 → 게임 Epic → 작업 Child를 분리한다.
- sandbox 또는 설정의 edit_directory 바로 아래 파일만 취급한다.
- 경로 이탈·심볼릭 링크를 차단한다. 현재 Epic에는 게임 폴더를 지정하지 않는다.
- 게임 실행은 도구 commit의 Git 제외 복사본과 게임 Child 설정을 사용한다.
- Street RPG 첫 화면에서 실제 create·Docker·에뮬레이터 연결을 확인했다.
- 화면 구성 Child는 12a7c42에 중간 결과를 보존하고 미완료로 중단했다.
- 게임 그래픽 반복 수정은 멈추고 자동화 도구 개발을 우선한다.
