## 현재 기능
- text: 응답 저장. python: 코드 저장·문법 검사. edit: 수정·Docker 검사.
- edit 작업에 target·prompt·test_module을 지정한다.
- 대상·테스트는 sandbox 바로 아래의 Git 추적 Python 파일로 제한한다.
- 대상·테스트의 기존 Git 변경, 잘못된 경로, 심볼릭 링크를 차단한다.
- 고정 테스트와 Docker 명령은 모델이 변경하지 않는다.
- Docker에 네트워크 차단·읽기 전용 마운트·자원 제한을 적용한다.
- 최대 3회 수정한다. 질문·중단 작업·수정 실패 시 목록을 멈춘다.
- 두 실행기에 잠금·외부 변경 검사를 적용하고 원본·시도·결과를 저장한다.
- validate_model.py는 outputs의 복사본으로 실제 모델을 검증한다.
- 모델: qwen3-coder:30b. Docker 이미지: python:3.11-slim.
