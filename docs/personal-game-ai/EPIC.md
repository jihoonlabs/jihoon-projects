## 목표

승인된 작업은 자율적으로 진행하고 중요한 결정은 사용자에게 묻는다.
외부 유료 API는 사용하지 않는다.

## 확정 방식
- main → Epic → Child 순서로 관리한다.
- 검증한 Child를 Epic에 통합한 뒤 다음 Child를 만든다.
- 작업 지침은 AGENTS.md와 현재 브랜치 전용 MD만 읽는다.
- 필요한 코드만 지정해서 읽는다.
- 다른 프로젝트의 변경과 미완료 파일을 보존한다.

## 현재 제한

- 입력 문맥 초과 여부는 아직 검사하지 않는다.
- 응답 길이 제한 감지 코드는 있으나 실패 경로는 미검증이다.
- 분석 내용의 정확성은 사용자 검토가 필요하다.
- 자동 수정·재시도·질문 생성·테스트 실행·Git 자동화는 미구현.
