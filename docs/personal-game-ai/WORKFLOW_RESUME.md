# 개인 게임 AI — 질문·답변 재개 검증

갱신일: 2026-10-05
브랜치: feature/personal-game-ai-workflow-resume

## 목표
- 실제 Ollama가 구현 중 질문하고 사용자 답변 후 같은 CLI로 재개하는 흐름을 검증한다.
- 사용자는 중요한 선택과 결과 확인을 맡고 반복 실행은 도구가 처리한다.

## 범위·규칙
- 같은 저장소 폴더를 사용하며 worktree를 만들지 않는다.
- 지침은 AGENTS.md와 이 문서만 사용한다.
- AGENTS.md는 수정하지 않는다. 개인 AI 문서는 한국어로 작성한다.
- 기존 untracked·stash·runner_tasks.json을 보존한다.
- 이번 승인은 Child 생성·개발·검사와 필요한 오류 수정까지다.
- commit·merge는 별도 승인한다. push·main 통합·브랜치 삭제는 하지 않는다.
- 설계·테스트의 SHA-256 검토와 고정 테스트 Git 보호를 유지한다.
- 새 테스트 commit이 필요하면 해당 파일을 안내하고 멈춘다.
- 실제 모델 응답과 모의 응답 검증을 구분해 기록한다.

## 이전 구현 계약
- workflow.py는 요청 JSON 하나로 설계·테스트 준비·설치·계획·실행을 연결한다.
- 설계 승인·테스트 확정·Git 준비에서 멈춘 뒤 같은 요청으로 재개한다.
- --answer와 --answer-text로 구현 질문에 답한다.
- 요청·문맥·검토 자료·설치 테스트·계획 계약의 변경을 검사한다.
- 프로그램은 Git commit·merge를 자동 수행하지 않는다.
- 실패한 작업·강제 종료 복구는 자동으로 진행하지 않는다.

## 현재 상태
- Epic 76fee53을 기준으로 작업했다.
- --review-design으로 현재 검토 설계의 수정본을 연결한다.
- 목표·필수 조건·문맥·원본 경로·SHA-256 수정 이력을 확인한다.
- 이전 설계와 상태 기록을 보존하고 새 설계는 별도로 승인한다.
- 테스트 생성 안내에 mock 작성·호출 검사·선행 함수 동일성 검사를 보강했다.
- 테스트 두 파일은 26a7c5c로 로컬 commit했다.
- 실제 회복·물약 구현은 각각 첫 시도에 지정 Docker 검사를 통과했다.
- 물약 모듈의 선행 heal import·함수 동일성·호출 인자·횟수·반환값 사용을 검사했다.
- 완료 재실행에서 모델 호출 없음·구현 변경 없음을 확인했다.

## 검증
- 수정 설계 연결 검사 4개를 포함한 전체 회귀 216개가 통과했다.
- 실제 모델의 수정 설계 연결·테스트 재시도·피드백·설치·의존성 구현을 확인했다.
- 최종 구현과 추적 파일 diff를 확인했다.
- 새 검사·구현 파일의 문법·공백 검사가 통과했다.
- 실제 모델이 질문 지시를 건너뛰고 완료했다.
- 따라서 실제 질문·답변 재개 검증은 완료하지 않았다.

## 제한·후속 판단
- 반드시 필요한 사용자 결정은 모델의 자발적인 질문만으로 강제할 수 없다.
- 필수 결정은 실행기가 확인하는 별도 조건으로 다룰 필요가 있다.
- 구조 검사와 지정 테스트는 게임 전체 품질이나 의미상 정확성을 보장하지 않는다.
- 문맥 변경 후 기존 승인·실행 기록은 당시 검토 이력으로 보존한다.
