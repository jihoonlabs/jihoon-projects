# 제품 목표 정리 — MANUAL

게임과 기기만 지정하고 중요한 기획을 선택하면 나머지 제작을 이어가는 도구라는 방향을 정리했다.

- 제품 목표: GOAL_V1.md
- 썸비 작업 연결: ../thumby/EPIC.md
- 기존 micropython/GOAL_V1.md는 문서 폴더로 이동했다.
- 일반 Thumby를 먼저 완성하고 Color 전용 프로필과 어댑터까지 확장하는 순서를 명시했다.
- 조사·기획 목표와 실제 구현·검증 상태를 분리했다. 모든 실행마다 승인받는 표현과 구현 가능성의 무조건 보장을 제거했다.

이번 변경은 문서만이다. 코드와 게임 실행에는 영향이 없으며 Ollama·Docker·실기 검증을 새로 수행하지 않았다. 집에서는 git으로 이 브랜치를 받은 뒤 제품 목표와 썸비 Epic을 읽고 실제 구현 브랜치의 MANUAL로 이어간다. 기존 outputs·생성 코드·승인 기록을 덮어쓰지 않는다. main과 다른 브랜치 코드를 merge하지 않았다.

원본 복사는 절대 금지한다. 원작을 참고한 독자적인 게임을 만들며 복제나 추출·변환을 제작 선택지에 넣지 않는다.

장르·플레이 형식·핵심 재미는 기기 한계 안에서 최대한 비슷하게 살리고, 축소할 요소는 명세 승인 전에 설명한다.

GOAL에 사용자가 원하는 여섯 게임의 장르·플레이 방향을 추가했다. 제작 순서나 원작 이식 승인을 의미하지 않으며, 실제 시작 시 기기 제약에 맞는 범위를 선택한다.
