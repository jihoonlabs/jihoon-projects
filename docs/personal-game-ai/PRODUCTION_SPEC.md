## 결과·계약
production_spec.py가 선택 기획과 scope/rules/controls/display_defaults/resource_budget/acceptance/unverified를 검토 명세로 묶는다. 각 값은 1~1000자 항목 1~20개의 목록이다. 기본값은 검토 후보이며 플레이로 확인되지 않은 값을 검증 완료로 표시하지 않는다.
명세 전체에는 입력·기기·조사·선택지·선택·정책·상세를 포함한다. 정렬된 JSON SHA-256으로 명세를 식별하고 --record/--approve의 명시 digest 입력으로 별도 제품 명세 승인 기록을 만든다. 내용 변경 시 이전 digest 승인은 거부한다. 정책·선택·자료 구조를 승인 직전에 재검사한다. 승인은 사용자 신원 증명·전자 서명이 아니며 도구 호출자가 명시한 의사 기록이다.
기존 engine의 설계 승인·테스트 확정 digest와 별개다. 기존 기록을 변경하거나 승계하지 않는다. 승인해도 게임 생성·모델·Git·Docker 호출 없음. 출력 파일은 새로 생성하며 원본 보존.

관련 58개 검사 통과. 명세 검토·명시 승인·내용 변경 거부·정책 보호·누락 차단·두 단계 CLI 저장을 확인했다. 실제 모델·화면·실기 검증 미실행.
명세 내용의 타당성·자원 예산·독창성은 사용자와 추가 검토해야 한다. 자동 명세 생성과 기존 workflow 요청 변환은 아직 없다. 다음은 승인된 명세를 대상 설정과 대조해 제작 요청으로 연결하는 책임이다. Color 생성 지원을 선언하지 않는다.
