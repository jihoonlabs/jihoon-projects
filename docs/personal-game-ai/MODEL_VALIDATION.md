## 목표·규칙

- 지침은 AGENTS.md와 이 문서만 읽는다.
- 같은 폴더에서 작업하며 worktree는 만들지 않는다.
- 기존 변경·untracked·stash·작업 목록을 보존한다.
- 문서는 최신 상태만 유지한다.

## 구현
- validate_model.py가 outputs의 복사본으로 실행기를 검증한다.
- 검증 중 경로와 Git 검사를 한시적으로 대체하며 기존 실행기는 변경하지 않는다.
- Git 검사는 원본 추적 파일에 적용한다. 복사본의 Git 검증은 대상이 아니다.
- 모델 요청·Docker 결과·작업 상태·요약을 저장한다.

## 최신 검증
- 유도된 구현 오류로 Docker 테스트 3개가 실패했다.
- 실제 모델이 실패 로그를 보고 두 번째 시도에 테스트 7개를 통과했다.
- 통과 후 후속 응답 작업이 실행됐다.
- 명시적인 질문 요청에 waiting_for_user를 저장하고 후속 작업을 중단했다.
- 원본 clamp와 고정 테스트 보존을 확인했다.
- 이번 Child 회귀 테스트 44개와 git diff --check 통과.
