# 개인 게임 AI — 작업 계획 Child

갱신일: 2026-10-03
브랜치: feature/personal-game-ai-task-plan

## 목표·규칙
- 승인된 목표를 파일 작업 목록으로 나누고 기존 실행기에 연결한다.
- 지침은 AGENTS.md와 이 문서만 사용한다. AGENTS.md 수정 금지.
- 같은 작업 폴더에서 기존 untracked·stash·runner_tasks.json을 보존한다.
- 수정본은 파일 전체, 개인 AI 문서는 한국어로 제공한다.
- 외부 유료 API는 사용하지 않는다.
- commit·push·merge는 승인 범위 안에서 수행한다.
- main 통합·Child 삭제는 하지 않는다.

## 구현
- plan_tasks.py: 목표와 허용 대상을 받아 계획을 생성한다.
- edit/create만 허용하며 대상마다 작업 하나를 생성한다.
- 모델은 대상·작업 종류·고정 테스트를 변경할 수 없다.
- 구조·중복·요청 길이·경로·Git 상태를 검사한다.
- 승인된 원래 목표를 각 실행 요청에 포함한다.
- 계획 형식 오류는 최대 3회 재시도하고 응답을 보존한다.
- 계획 생성 중 대상·고정 테스트·작업 문맥 변경을 확인한다.
- 계획과 로그는 outputs/plan_*/에 새로 저장한다.
- execute_plan.py: 별도 계획 목록을 기존 실행기로 처리한다.
- 기존 목록을 덮어쓰지 않고 실행 잠금·질문 답변 재개를 재사용한다.
- failed 작업이 있는 계획은 실행을 차단한다.
- 실행 연결은 전용 CLI 프로세스에서 사용한다.

## 검증
- 기존 회귀와 신규 모의 테스트 총 117개 통과.
- 실제 모델로 목표→계획→파일 생성→Docker 검사 연결 확인.
- 단일 대상 생성은 첫 시도에 고정 테스트 6개 통과.
- 두 대상 계획에서 회복·구매 파일을 순차 생성했다.
- 두 파일 모두 첫 시도에 각각 고정 테스트 3개·4개 통과.
- 생성된 세 함수의 코드와 diff 검사를 확인했다.
- 신규 계획 연결의 실제 질문·답변 재개는 아직 미검증이다.

## 제한
- 대상 파일·작업 종류·고정 테스트는 사람이 지정한다.
- 현재 검증한 두 작업은 서로 독립적이다.
- 파일 구성·테스트 자동 설계·의존성·동일 파일 연속 수정은 미지원이다.
- 계획의 의미상 적절함은 구조 검사만으로 보장하지 않는다.
- 계획 생성 잠금과 응답 전체 분량 제한은 미구현이다.
- 실행 연결은 모듈의 목록 경로를 임시 변경하며 동시 스레드 호출은 지원하지 않는다.
- 장시간 무인 실행·강제 종료 복구·Git 자동화는 미검증 또는 미구현이다.
- 테스트 통과는 지정 검사 범위만 보장한다.
