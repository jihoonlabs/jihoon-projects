## 목표
- 일반 Thumby용 게임 폴더 하나를 개인 AI의 자동 수정·검사에 연결한다.
- 첫 게임은 독자적인 시대극 액션 RPG다.
- 기존 작품은 장르 참고이며 이름·캐릭터·그래픽·음악·맵은 새로 만든다.
- 작은 화면에서도 인상적인 그래픽과 실제 진행 가능한 게임을 목표로 한다.
- 콘텐츠 우선순위는 상점·성장, 싸움·무기, 지역 이동, 동료 순서다.
- Thumby Color는 이후 별도로 진행한다.
- 장기 목표는 로컬 AI가 승인된 목표를 작업으로 나누고 구현을 이어가는 것이다.
- 이번 Child는 지정 파일 자동 수정의 실제 게임 연결까지로 제한한다.

- AGENTS.md와 이 문서만 작업 지침으로 읽는다.
- AGENTS.md는 수정하지 않는다.
- 수정본은 파일 전체로 제공한다.
- 기존 untracked 5개와 stash 1개를 보존한다.
- 기존 runner_tasks.json을 덮어쓰거나 실행하지 않는다.
- commit·push·merge·브랜치 삭제는 별도 승인 전 수행하지 않는다.

## 연결 계약
- 게임 폴더는 micropython/street_rpg/다.
- game/파일.py는 해당 폴더 바로 아래 파일로 연결한다.
- sandbox/파일.py의 기존 동작도 유지한다.
- 수정 대상과 고정 테스트는 Git 추적 상태이며 기존 변경이 없어야 한다.
- 테스트 모듈은 같은 폴더의 test_로 시작하는 Python 모듈이다.
- 경로 이탈·프로젝트 내부 심볼릭 링크·외부 변경을 차단한다.
- 고정 테스트와 Docker 명령은 모델이 수정하지 않는다.
- Docker는 선택한 폴더만 읽기 전용으로 마운트한다.
- 네트워크 차단과 기존 자원 제한을 유지한다.
- 질문 시 원본 복원, 답변 저장 후 재개 계약을 유지한다.

## 첫 실제 모델 작업
- 대상: game/movement.py
- 고정 테스트: test_movement
- 함수: move_player(x, y, dx, dy, max_x, max_y)
- 정수 입력과 0 이상인 최대 좌표를 전제로 한다.
- 이동 후 x는 0..max_x, y는 0..max_y 범위로 제한한다.
- 화면·캐릭터 크기는 호출하는 쪽에서 계산한다.
- 대각선 이동은 두 축의 입력을 그대로 적용한다.
- 이번 함수는 그래픽·버튼 API·충돌·전투를 다루지 않는다.
