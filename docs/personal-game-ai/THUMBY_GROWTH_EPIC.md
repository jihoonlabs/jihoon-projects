# ThumbyGrowth 게임 Epic

## 목표와 범위
일반 Thumby 72x40 안에서 주요 게임 구성이 한 바퀴 돌아가는 축소판 액션 RPG를 만든다.
오프닝·국가/도시·전투·돈/구매/성장·구입형 기술·이벤트·저장·엔딩의 연결이 중심이다. 타격감 극대화보다 구성의 완결성을 우선한다.
배경은 중세풍 한국 5·중국 5·일본 5, 총 15스테이지로 한다.
가장 큰 목적은 실제 플레이 가능한 Thumby 게임을 만드는 것이다. 집에서는 Ollama, 외부에서는 가능한 AI가 같은 Git을 이어받는다.
대화 실행 기능과 도구 개선은 이 게임 제작을 위한 수단으로 유지한다.
안정성과 효율화를 우선하며 게임 구현, 자동 검증, 실제 기기 플레이를 구분한다.
Ollama 도구 Epic `feature/personal-game-ai`와 게임 Epic을 구분한다.

## 현재 업그레이드 상태
- 사용자 목표: 쿠니오군 시대극 같은 시스템, 중세풍 한국 5·중국 5·일본 5.
- 시작 국가는 KR/CN/JP 중 자유 선택. 나라의 도시 5개를 클리어하면 남은 나라 중 다음 나라를 선택한다.
- 15승 뒤 엔딩. 국가 이동에서 돈·장비를 유지하고 진행 순서를 저장한다.
- 도시 이름은 임시 기획이며 정확한 역사 복원이 아니다. 도시 목록: THUMBY_GROWTH_PLAYABLE.md.
- 방향키 이동, A 손 공격, B 발 공격, A+B 상태창. 상태창에서 능력치·돈·도시 확인/저장.
- 손/발은 방향 타격과 공통 재사용 시간을 사용한다. 발은 거리 10/20프레임, 손은 거리 8/15프레임.
- 적은 12프레임 전조 후 타격한다. 맞히면 전조 취소+손 8/발 12프레임 경직, 발은 3픽셀 밀림. 피격 깜빡임 6프레임.
- 전조 중 적의 이동은 멈추며 회피해도 공격 후 120프레임 회복을 거친다. 상태창은 전투 타이머를 멈춘다.
- 이식 판단: MicroPython으로 게임성을 먼저 구현하고 실기 병목을 측정한다. 성능 부족 시 C/C++ 이식 검토. 언어를 목표로 고정하지 않는다.
- 저장 version=2에 route를 추가했다. 옛 version=1 저장을 읽으며 5/10승은 다음 국가 선택 화면으로 이어진다.
- 15종 배경, 배경/바닥 스크롤 분리, 캐릭터 대비 보호를 적용했다.
- 8×8 인물은 몸통/걸음을 공유하고 머리 5종만 구분한다. 6×7 충돌과 발 위치는 유지한다.
- 전투 HUD는 하트/적 아이콘+체력 숫자로 줄였다. 도시/돈/장비 상세는 안전 화면·상태창에서 확인한다.
- 배경 건물을 y=14..20으로 축소하고 바닥 y=21..39를 비웠다. 세 깊이의 바닥 표식으로 앞뒤 이동을 보이게 한다. 이동 범위/판정은 유지한다.
- 공유 캐릭터/HUD 원시 그림 35바이트, 전용 연출 4컷 1,152바이트. 연출은 기본 blit 한 번으로 그린다. 전투 표본 최대 사각형 호출 80회. 전체 메모리/FPS는 미측정이다.
- 게임 검사 91개·AI 도구 검사 401개 통과. 공유 부품/반전/화면 경계/연출/음악과 opt-in bitmap API 제한 포함.
- 공개 일반 Thumby 게임 4개를 구조 참고했다. 코드/스프라이트는 복사하지 않았다.
- 현재는 1대1 전투 초안. 복수 적은 동시 4명 이하를 목표로 1–2명부터 확장한다.
- 점프·잡기·던지기·복수 적·이동 지도는 미구현. 실기 FPS·메모리·조작감은 미검증.
- 같은 Epic에서 커밋·푸시한다. 사용자 지시에 따라 merge하지 않으며 새 브랜치/worktree를 만들지 않는다.
- 알아보기 어려웠던 임시 연출을 전용 72×32 흑백 그림으로 교체했다. 성문에서 출발→세 목적지, 승리→귀환. 국가 이벤트는 승리 그림을 공유한다. A/B 건너뛰기와 상태/음악 흐름은 유지한다.
- 짧은 자작 단음 BGM을 추가했다. 기본 audio.play/stop만 허용하고 playBlocking/음소거 강제 해제는 허용하지 않는다. 상태창/패배는 정지, 클리어 음악은 한 번만 재생한다.
- 다음 우선순위는 상점의 총/회복/스탯 성장과 구입형 기술을 연결하는 것이다. 전투 수치/그림의 과도한 개선을 앞세우지 않는다.
- 다음 기능의 중심은 전투→돈→구매→성장이다. 상점에 낮은 피해/장거리 권총, 근거리 칼, 회복템, 스탯 성장, 구입형 필살기를 연결한다. 아직 구현된 기능으로 취급하지 않는다.
- 필살기는 구입해야 커맨드로 사용한다. 방향 두 번+공격 버튼 형태를 목표로 하며 이동/A+B 상태창과 충돌하지 않도록 유효 시간·해금·오입력을 검사한다.
- 공개 Thoom/Thumbylina에서 배울 표현·재사용 기법과 확인 수준은 VISUALS의 마지막 절에 정리했다. 전투 공유 인물/큰 얼굴 컷/명암을 용도별로 사용하며, 다음 게임에도 현재 helper를 재사용한다. 새 엔진보다 빠진 구성 연결을 우선한다.
