# 개인 게임 AI — 작업 의존성 Child

갱신일: 2026-10-03
브랜치: feature/personal-game-ai-task-dependencies

## 목표·규칙
- 선행 작업이 만든 모듈을 후속 구현에서 재사용하도록 연결한다.
- 지침은 AGENTS.md와 이 문서만 사용한다. AGENTS.md 수정 금지.
- 같은 작업 폴더에서 기존 untracked·stash·runner_tasks.json을 보존한다.
- 수정본은 파일 전체, 개인 AI 문서는 한국어로 제공한다.
- 외부 유료 API와 공개 push는 사용하지 않는다.
- commit·merge는 승인 범위 안에서 수행한다.
- main 통합·Child 삭제는 하지 않는다.

## 구현
- depends_on으로 같은 계획의 선행 작업 ID를 지정한다.
- 없는 ID·중복·자기 참조·순환을 차단하고 선행 작업부터 정렬한다.
- 기존 독립 계획은 기존 실행 흐름을 유지한다.
- 의존성 계획은 선행 작업이 tests_passed일 때만 후속 작업을 실행한다.
- 성공한 코드와 대상·고정 테스트의 SHA-256을 계획에 기록한다.
- 현재 파일과 기록이 일치하는 선행 코드를 후속 요청에 전달한다.
- 모델 호출 전후와 작업 종료 후 선행 파일 변경을 검사한다.
- 질문·실패·중단 시 후속 작업을 멈춘다.
- 재개 시 선행 결과를 다시 확인하고 누적 답변을 전달한다.
- 선행 코드·누적 답변을 포함해 요청 4000자 제한을 적용한다.
- 재개 성공 후 이전 질문이 남는 문제를 수정했다.

## 검증
- 기존 회귀와 계획·의존성 검사 총 132개 통과.
- 모의 검사로 순서·코드 전달·재개·실패 중단·외부 변경·길이 제한을 확인했다.
- 실제 모델이 회복→물약 의존성을 지정하고 두 모듈을 순차 생성했다.
- 두 모듈 모두 첫 시도에 실제 Docker 검사 3개·5개를 통과했다.
- 후속 모듈의 선행 함수 import·재사용을 고정 테스트로 확인했다.
- 생성 코드·문법·끝 공백·diff 검사 통과.
- 기존 untracked·stash 보존 확인.

## 제한
- 실제 의존성 계획의 질문·답변 재개는 아직 미검증이다.
- 의존성 실행은 전용 CLI 프로세스용이다.
- 파일 구성·고정 테스트는 사람이 준비한다.
- 동일 파일 연속 수정·테스트 자동 설계·Git 자동화는 미지원이다.
- 선행 코드가 크면 요청 제한으로 실행을 중단한다.
- 전체 의존 코드의 완전한 동시 변경 방지와 결과 기록의 원자성은 보장하지 않는다.
- 장시간 무인 실행·강제 종료 복구는 미검증이다.
- 테스트 통과는 지정한 검사 범위만 보장한다.
