# 개인 게임 AI — 구현 연결

갱신일: 2026-10-04

기준 Epic commit: 81a0017

## 목표
- 게임 내용을 입력하면 로컬 AI가 제작하고 사용자가 플레이 테스트한다.
- 대상은 Thumby, Thumby Color, 스타크래프트 1 리마스터 유즈맵이다.
- 이번 Child는 Python 로직의 설계→테스트 설치→구현 계획→Docker 검사를 연결한다.
- 플랫폼별 제작 연결과 그래픽 작업은 이번 범위에서 제외한다.

## 규칙
- 지침은 AGENTS.md와 이 문서만 사용한다.
- 같은 저장소 폴더를 사용한다. worktree·AGENTS.md 수정 금지.
- 개인 AI 문서는 한국어로 작성한다.
- 기존 untracked·stash·runner_tasks.json을 보존한다.
- commit·merge는 승인 범위만 수행한다.
- push·main 통합·브랜치 삭제는 하지 않는다.

## 구현
- implementation_link.py에 확정 테스트 설치와 구현 계획 생성을 추가했다.
- 설계·승인·후보·확정 기록의 SHA-256과 현재 문맥을 확인한다.
- 표시용 후보와 설치 테스트의 내용 일치를 검사한다.
- 설치는 기존 파일·Git 추적 경로·ignore 경로를 차단한다.
- 설치는 기존 파일 작업 잠금을 공유하며 테스트를 실행하거나 import하지 않는다.
- 설치 중 오류로 일부 파일이 생성됐으면 삭제하지 않고 확인을 요구한다.
- 구현 계획은 설치 테스트의 Git 추적·변경 없음을 요구한다.
- 함수 계약·검사 사례·의존성을 기존 create 계획으로 변환한다.
- 계획은 outputs/plan_*/tasks.json에 저장하고 자동 실행하지 않는다.
- 기존 execute_plan의 Docker 검사·재시도·질문 후 재개를 재사용한다.
- 프로그램은 Git add·commit을 자동 실행하지 않는다.
- 설계·테스트 프롬프트에 필드 형식·파일별 import·구현 범위 안내를 보강했다.

- 신규 단위 검사 8개를 포함한 전체 회귀 188개 통과.
- 실제 후보 확정·설치와 미추적 테스트의 계획 생성 차단 확인.
- 테스트 설치 commit: cd6b2a6, 21f5eca.
- 초기 구현은 결과값 검사에 통과했지만 함수 중복·재사용 누락을 발견했다.
- 별도 검증 설계와 테스트로 함수 동일성·mock 호출 인자·횟수·반환값 사용을 확인했다.
- linked_health_probe.py와 linked_potion_probe.py는 각각 첫 시도에 Docker 검사 통과.
- 생성 코드의 파일별 함수 범위를 별도 AST 검사로 확인했다.
- 완료 계획 재실행·문맥 검사·추적 및 새 파일 공백 검사 통과.
- 실패 후보와 초기 생성 파일은 보존했다.

## 제한
- 구조 검사는 의미상 정확성·검사 충분성·안전성을 보장하지 않는다.
- 이번 mock 재사용 검사는 구체적인 검토 피드백을 추가한 모델 호출로 생성했다.
- 의미상 후보 수정 피드백은 아직 일반 CLI 기능으로 제공하지 않는다.
- 함수 범위 검사는 이번 검증 명령에서 수행했고 실행기 내부 강제 검사는 아니다.
- 완료 계획 재실행은 검증했지만 이번 연결의 실제 질문·답변 재개는 별도 미검증이다.
- 설치의 전체 원자성·강제 종료 복구·장시간 무인 실행은 보장하지 않는다.
- 도구 개발 자동화·Git 자동화·플랫폼별 게임 전체 제작은 아직 미완성이다.
- 문맥 변경 전 승인·확정 기록은 당시 검토 이력으로 보존한다.
