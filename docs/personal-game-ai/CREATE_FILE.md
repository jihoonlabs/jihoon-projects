## 생성 계약
- sandbox 또는 지정 게임 폴더 바로 아래의 없는 Python 파일만 생성한다.
- 기존 파일·삭제된 Git 추적 파일·ignored 경로·심볼릭 링크를 차단한다.
- 고정 테스트는 Git 추적 상태이며 기존 변경이 없어야 한다.
- 성공하면 생성 파일을 남긴다.
- 질문·최종 실패·처리 가능한 실행 오류에서는 이번 생성 파일만 정리한다.
- 외부 변경 감지 시 파일을 제거하지 않고 중단한다.
- 후보·응답·검사 결과는 outputs에 보존한다.
- edit와 같은 잠금 및 기존 Docker 격리·자원 제한을 사용한다.
- 작업 목록의 kind=create와 누적 답변 후 재개를 지원한다.
