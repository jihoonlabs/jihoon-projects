# 개인 게임 AI — 질문 후 재개

갱신일: 2026-10-03
브랜치: feature/personal-game-ai-resume

## 목표·범위
- 질문에 사용자 답변을 받은 뒤 해당 작업을 재개한다.
- 작업 의존성, running·failed 복구, Git 자동화는 제외한다.
- AGENTS.md를 따르며 해당 파일은 수정하지 않는다.
- 같은 폴더에서 작업하고 기존 untracked·stash를 보존한다.
- 수정 안내는 파일 전체로 제공한다. 개인 AI 문서는 한국어로 작성한다.

## 구현
- --answer 작업ID로 질문을 표시하고 답변을 입력받는다.
- 원래 요청은 변경하지 않고 누적 질문·답변을 작업 목록에 저장한다.
- 질문 시 외부 변경을 검사한 뒤 대상을 실행 전 원본으로 복원한다.
- 시도한 코드와 실행 기록은 outputs에 보존한다.
- 재개 요청에 원래 요청과 누적 질문·답변을 전달한다.
- 기존 경로·Git·잠금·고정 테스트 검사를 재개에도 적용한다.
- 질문·답변을 포함한 수정 요청은 기존 4000자 제한을 적용한다.
- 재개 실행마다 최대 3회 수정한다.
- 수정 성공 후 후속 작업을 진행하며 질문·수정 실패 시 멈춘다.
- 다른 미해결 질문이 있으면 답변은 저장하되 실행은 멈춘다.
- running 작업이 있으면 답변 저장과 실행을 멈춘다.
