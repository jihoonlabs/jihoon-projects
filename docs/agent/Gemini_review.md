## 主要技術スタック

- **Frontend:** Next.js, React, TypeScript, Zustand, dnd-kit, Tailwind CSS
- **Backend:** Laravel, PHP, Sanctum
- **Quality Assurance:** Vitest, Testing Library, PHPUnit, ESLint
- **Workflow:** AI支援プロセス設計 (AGENTS規約に基づくテスト駆動・責務分離開発)

## 実装における技術的工夫

1. **状態管理とUX最適化:** dnd-kitによるUI描画とZustandを用いたローカル状態管理を組み合わせ、API通信のオーバーヘッドを感じさせない軽快な操作性を実現。
2. **テスト駆動・品質保証:** Vitestによるコンポーネント検証と、PHPUnitによるAPI/認可ポリシーのテストを整備。
3. **安全な認証設計:** Laravel SanctumによるSPAセッション認証を採用し、CSRF対策と安全な権限管理を両立。
