# WORKテンプレート v2.2

このファイルは、作業AIが個別のWORKを作るときの記入形式です。ここに特定プロジェクトの作業指示や進捗を記録せず、作業ごとに対象プロジェクトの所定の場所へコピーして記入します。

## 目的

何を完了する作業かを、短く具体的に書く。

## 範囲

- 変更する機能・文書・対象範囲
- 作業で行うこと

## 対象外

- 今回は変更しないこと
- 判断や承認が必要な別作業

## 前提と参照先

- 作業に必要な仕様、ファイル、既存の判断
- 不明な点や確認が必要な前提

## 完了条件

- 作業完了を確認できる状態
- 必要なレビューや統合の条件

## 検証

- 対象commit SHA（未コミット変更がある場合はその範囲）
- 実行したコマンド・方法と終了コードまたは結果
- 証拠の場所: CI実行ID、公開可能なcommit・PR・ログへの参照。保存していなければ「未保存」と明記
- 状態: 成功 / 失敗 / 環境による実行不能 / 未実行
- 未実行の場合に未検証として記録する項目

## 改善メモ（実際に問題を観測した場合のみ）

- 期待した行動 / 実際の行動 / 証拠 / 作業への影響 / 最小の改善案
- 問題がなければ記入不要。規則に不要な確認・待機も、根拠がある場合だけ記録する。
- 公開できない情報は含めず、ログ全文を重複して貼り付けない。

## 現在の状態

- 状態: 未着手 / 進行中 / 完了 / 保留
- 完了したこと:
- 残っていること:
- 未検証・制約:

## 記入上の注意

- 作業に必要な情報だけを残し、AGENTSやコードと重複する説明を増やさない。
- 複数の責任がある場合は、境界・依存・統合条件を明記する。
- 作業固有の詳細は対象プロジェクトのWORKに書く。このテンプレート自体を進捗記録に使わない。
- 完了報告は [MANUALテンプレート v2.2](MANUAL-v2.2.md) の形式で作成する。
