# AGENTS v2.1 改善作業 — WORK

## Version

v2.1

## 目的

実作業と独立レビューで見つかった改善点を反映し、AGENTS v2の基本構造を保ちながら、自律判断・作業分割・引き継ぎ・検証の境界を明確にする。

## 対象範囲

- 公開用のAI作業ルール（AGENTS v2）
- 実作業で明確になった改善候補と、内容を確認した独立レビュー
- 対象外: Ticketアプリの機能実装、特定モデルやIDEだけに依存する規則

## 採用した判断

- 既存コード・テスト・契約から安全に決められる小さな事項は自律判断し、結果を変える選択はユーザーに確認する。
- 作業を必要な責任単位に分け、Childの結果・境界・依存・検証・未解決点を引き継ぐ。Parentは採用したSHAと統合状態を記録する。
- 変更に近い有効な検証から始め、影響に応じて広げる。未実行は未検証として残す。
- 無関係なdirty/untracked変更を保護しつつ、それだけで無関係な作業を止めない。
- AGENTSの改善提案を各作業に強制せず、実作業で根拠が見つかった場合に扱う。
