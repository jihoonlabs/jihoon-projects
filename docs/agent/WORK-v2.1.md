# WORKテンプレート v2.1

このファイルは、作業AIが個別のWORKを作るときの記入形式です。ここに特定プロジェクトの作業指示や進捗を記録せず、作業ごとに対象プロジェクトの所定の場所へコピーして記入します。

## 目的

何を完了する作業かを、短く具体的に書く。

## 範囲

- 変更する機能・文書・対象範囲
- 作業で行うこと

## 対象外

- 今回は変更しないこと
- 判断や承認が必要な別作業

## 前提と参照先

- 作業に必要な仕様、ファイル、既存の判断
- 不明な点や確認が必要な前提

## 完了条件

- 作業完了を確認できる状態
- 必要なレビューや統合の条件

## 検証

- 実施する検証
- 未実行の場合に未検証として記録する項目

## 現在の状態

- 状態: 未着手 / 進行中 / 完了 / 保留
- 完了したこと:
- 残っていること:
- 未検証・制約:

## 記入上の注意

- 作業に必要な情報だけを残し、AGENTSやコードと重複する説明を増やさない。
- 複数の責任がある場合は、境界・依存・統合条件を明記する。
- 作業固有の詳細は対象プロジェクトのWORKに書く。このテンプレート自体を進捗記録に使わない。
- 完了報告は [MANUALテンプレート v2.1](MANUAL-v2.1.md) の形式で作成する。
