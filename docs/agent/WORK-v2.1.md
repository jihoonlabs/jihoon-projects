# 作業MD（WORK）の書式 v2.1

AIが作業を始める・再開するときに読む、作業単位ごとの契約と現在状態です。会話の記録ではなく、次に何をすべきかが分かる最小限の内容だけを書きます。

```md
# <作業名> WORK

## 目標
<この作業で実現すること。1〜2行>

## 範囲
- 対象:
- 対象外:

## 必要な文脈
<読むべきコード・テスト・前提。作業に必要なものだけ>

## 完了条件
- <検証で確認できる形で書く>

## 検証
- 実行したもの / 結果:
- 未実行・未検証:

## 現在の状態
- 状態: 未着手 / 作業中 / 検証待ち / 完了
- 次の行動:

## 引き継ぎ（Childのみ）
- 結果のcommit SHA:
- 変更した境界:
- 依存関係・統合時に維持する前提:
- 残る制約・未検証事項:
```

## 書き方
- 実装の事実はGit・コード・テストを正とし、コードから分かる履歴は書かない。
- 判断・検証・中断のたびに「現在の状態」を更新する。
- 未実行の検証は未検証と明記し、報告を実態より先行させない。
