# AGENTS v2.1 改善作業 — WORK

> 公開ポートフォリオ用に抽象化した、完了済みの文書改善タスク例です。製品機能の作業指示ではありません。

## 目的

AI作業ルールを、必要な場面で自律性を保ちつつ、作業分割・引き継ぎ・検証・統合の状態を追える形に整理する。

## 作業範囲

- 対象: `docs/agent/AGENTS-v2.1.md` の作業開始、責任分担、文書、検証、Gitに関するルール
- 対象: 実作業とレビューで根拠が確認された改善のみを反映すること
- 対象外: Ticketアプリのコード、API、UI、テストの変更
- 対象外: 特定のAIモデルやIDEに依存する手順の追加

## 完了条件

- 安全に判断できる小さな実装判断は自律的に進め、結果に影響する選択は確認する。
- Parent/Childの責任、引き継ぎ情報、統合後の確認対象を区別する。
- 変更に近い検証から始め、未実行の確認を未検証として扱う。
- 無関係なGit変更を保護し、範囲外の変更や競合を勝手に解消しない。
- AGENTS、WORK、MANUALがそれぞれルール、作業契約、ユーザー向け結果報告として読める。

## 実施と結果

1. 既存ルールと実作業で確認された改善候補を整理した。
2. 複数の独立レビューを比較し、根拠のある変更だけを選んだ。
3. 既存の責任分担と分割・統合の考え方を保ちながら、判断範囲・引き継ぎ・検証・Git状態の扱いを明確にした。
4. 公開用のAGENTS、WORK、MANUAL間で目的と記述を照合した。

## 状態

完了。v2.1を公開資料として確定した。変更内容と確認範囲は [MANUAL v2.1](MANUAL-v2.1.md)、ルール本文は [AGENTS v2.1](AGENTS-v2.1.md) を参照。
