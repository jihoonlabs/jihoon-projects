# AGENTS改善 WORK

## Version
v2.1 independent re-review candidate

## Goal
v2.1の構造を増やさず、自律性・Child handoff・統合・検証の最小ルールが実運用に十分か再確認する。

## Findings
- ユーザー確認条件は、新仕様・公開契約・責任範囲等の実質的な判断に絞られており、追加の停止条件は不要。
- Childの採用commit SHAをParentが所有する方式は、異なるAI・端末間でも採用物を一意に固定できる。SHAだけで統合成功を表現せず、統合状態と接続・回帰検証を別に持つ現行方式を維持する。
- 上位→下位の分解、検証済み下位→上位の統合順は十分明確で、追加の階層ルールは不要。
- Child handoffでは、成功した検証だけでなく残る制約と未検証条件が失われないことが必要。
- 検証は固定のfull suiteではなく、変更に近い検証から影響範囲へ広げる方がfeedbackと安全性を両立できる。
- AGENTS、WORK、MANUALの役割分離は維持し、特定AI・IDE・固定context量・未経験リスク向けの規則は追加しない。

## Decision
AGENTS.mdに新しい節は追加しない。
既存のChild handoff文へ「残る制約・未検証」を統合し、既存の検証文を「近い検証→影響範囲」へ置き換える。
その他の自律性、SHA管理、逆順統合、Git安全性、context方針は維持する。

## Validation target
次の新規作業から、以下を観察する。
- 不要な質問・停止が増えないか
- Child→Parent統合時に制約・未検証条件が欠落しないか
- 採用SHAと統合状態が混同されないか
- 検証時間を過度に増やさず回帰を捕捉できるか
