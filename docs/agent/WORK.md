# AGENTS改善 WORK

## Version
v2.1 independent re-review

## Goal
現在のv2.1を基準に、規則を増やさず自律性・統合安定性・検証効率を再確認する。

## Findings
- v2.1で、広すぎた停止条件、無関係なdirty状態による停止、Child統合状態の曖昧さは十分に改善されている。
- 分解を上位→下位、統合を検証済み下位→上位とする規則は明確で、AIや端末を跨ぐ分業にも追加の専用機構は不要。
- Childの採用commit SHAをParentが所有する方式は十分な識別子になる。別の状態管理層は追加しない。
- handoffには検証成功だけでなく、Parentの判断に影響する残る制約・未検証条件が必要。
- 検証は変更近傍から開始して影響範囲へ広げる方が、常時フルテストより効率と安全性のバランスがよい。

## Decision
AGENTS.mdの実質変更はhandoffと検証の2点だけとする。
既存の自律判断境界、Git保護、Router方式、AI-agnostic方針は維持する。
固定コンテキスト量、固定テスト量、追加の状態ファイル、特定AI向け規則は追加しない。

## Validation target
次の新規作業で、不要な停止を増やさずChildの制約がParentへ引き継がれるか、変更規模に応じた検証で統合回帰を捕捉できるかを観察する。
