# AGENTS改善 WORK

## Version
v2.1 re-review candidate

## Goal
v2.1 HEADを基準に、規則を増やさず自律性・統合安定性・引継ぎ精度を再確認する。

## Re-review findings
- v2.1の基本構造、停止条件、Git保護、上位→下位の分解と下位→上位の統合は維持できる。
- Childの「検証結果」だけでは、環境不足などで実行できなかった検証や既知制約がParentへ伝わらない可能性がある。これは統合判断に直接必要なためhandoffへ含める。
- 現行の検証規則は「責任範囲に応じたテスト」が妥当だが、弱いAIでも検証範囲を選びやすくするため、変更に最も近い検証から影響範囲に応じて広げる順序だけ明示する。
- commit SHAはChild成果物の識別と採用状態の追跡には十分。ただしSHAだけを品質保証にせず、Parent側の契約・接続点・回帰検証を維持する。
- 新しい状態ファイル、固定テンプレート、AI製品固有ルール、強制フルテストは不要。

## Candidate changes
1. Child handoffに「残る制約・未検証事項」を追加する。
2. 検証を「変更に最も近い検証 → 影響範囲に応じて拡張」とする。
3. それ以外のAGENTS規則は増やさない。

## Validation target
次の新規作業から、不要な停止、Child→Parentの情報欠落、採用SHAと検証状態、contextコストを観察する。
