# AGENTS 独立review候補

基準: `docs/agents-v2`

## 主な変更
- AGENTSを通常作業で毎回必要なルールへ絞り、AGENTS改善プロセスの詳細を削除した。
- 「最小コンテキスト」を固定的な読取制限ではなく「小さく開始し、必要な依存へ自律的に広げる」方式にした。
- 既決定範囲では質問せず、調査・実装・検証・明白な回帰修正まで進めることを既定にした。
- Child統合はmergeでは完了せず、共有契約・接続点・親範囲の回帰検証までを統合側の責任とした。
- Git規則を、他作業の変更保護・許可された操作範囲・main直接変更禁止・最終diff確認に集約した。
- WORKは検討根拠、MANUALは人間向け要約とし、実行規則の重複を減らした。

## 判断
v2の安全性は維持しつつ、AIが毎回読む規則を減らす方が現在の作業形態に合う。特にEpic/Child運用では、Childを細かくすること自体より「独立性」と「統合時の再検証」を強制する方が効果が高い。

新しいPLANS.mdや追加のagent文書は作らない。現在の作業MDが計画・再開情報を担えるため、文書を増やす利益よりcontextと同期コストの方が大きい。
