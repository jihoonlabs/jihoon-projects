# AGENTS v2 更新報告

更新候補作成日: 2026-10-07

## 今回整理したこと
AIが読む作業文書と、ユーザーが読む作業報告を分離する方針を追加しました。

- 作業MD: AIが実装を継続するための目標、範囲、完了条件、検証、現在状態を管理します。
- MANUAL: ユーザー向けに、実際に追加・変更した機能、簡単な実装方法、テスト結果、影響、制約、mainへ統合する判断材料を説明します。

## 分業・統合の改善
これまでの「1 Child = 1責任」は維持します。
一方、個々のChildが成功しても統合時に壊れる弱点を減らすため、次を追加しました。

- Childが上位へ提供する結果と依存関係を明確にする。
- 統合前にChild同士の前提や共有境界が矛盾していないか確認する。
- mergeできたことだけを成功としない。
- 統合後にAPI、データ、権限、状態、UI操作などChild同士の実際の接続点を再検証する。
- 接続上の明白な回帰は統合責任として修正し、新仕様が必要ならユーザーへ確認する。

## AGENTSの更新方法
作業が一区切りした時に、その作業から改善点が見つかったか確認します。
何もなければAGENTS関連作業はスキップします。

改善点がある場合はこのフォルダに候補を蓄積し、coding agentの最新トレンドも合わせて整理します。
AGENTS.mdそのものはユーザー承認なしに変更しません。

## 既存作業への影響
現在進行中のTicket作業にはこの新ルールを適用しません。
現在のTicket作業は開始時のルールで完了させます。

今回の更新候補は、Ticket作業終了後に新しく開始するブランチから適用する想定です。
