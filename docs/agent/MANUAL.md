# AGENTS independent review

更新日: 2026-10-07

## 結論
v2の「最小コンテキスト・1責任・統合後検証」の方向は維持し、通常作業に不要なmeta-ruleを削除した。AGENTSは日常作業で毎回効くguardrailとnavigationに限定する。

## 主な変更
- AGENTS改善サイクルをAGENTS本体から削除。改善活動は通常実装の必須手順にしない。
- 「不確実なら確認」を狭め、既存パターンで安全に進められる調査・実装・回帰修正は自律実行する。
- Child統合の責任を明確化。親でshared boundaryと代表フローを検証し、merge成功だけで完了にしない。
- 検証を「近いテスト → 影響範囲の回帰 → 必要な型/Lint/build/browser」の段階式にして、毎回の過剰検証を避ける。
- MDの役割を分離し、同じ情報を親/Child/WORK/MANUALへ重複保存しない。
- Gitのdirty state保護と破壊的操作の承認境界は維持する。

## 判断理由
このrepositoryではEpic/Child分業そのものより、独立したChildを親へ戻した後のAPI・DB・権限・状態・UI等の接続点が主な統合リスクになる。一方、全履歴MDの読込、全テストの機械的再実行、曖昧さごとの質問はコンテキストと待ち時間を増やす。したがって「局所作業は自律的に、共有境界と不可逆判断は厳格に」を基準にした。

## 適用
これは `docs/agents-v2` を変更しない独立候補であり、他候補と比較して採用判断するためのreview版。mainへの適用は行っていない。
