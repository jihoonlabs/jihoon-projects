# AGENTS v2.1 再review報告

基準commit: `be26cb1300ba274370513226c4ac53cf4bd1e610`

## 結論
現在のv2.1はそのままでも運用可能。構造変更やv3化は不要。
再reviewでは、実際のhandoffと検証判断に直接効く2点だけを小さく補強した。

## 維持
- 確定方針内では自律実行し、結果を変える未決定事項だけ確認する。
- 必要時のみChildへ分割し、上位→下位に分解、検証済み下位→上位に統合する。
- Parentが採用commit SHAと最終統合状態を所有する。
- merge成功ではなく、契約・接続点・親範囲の回帰まで確認する。
- 無関係なdirty/untrackedを保護しつつ、それ自体では作業を止めない。
- Gitと作業MDをAI/環境間の共通状態として使い、特定AI・IDEを前提にしない。

## 修正
- Child handoffに残る制約・未検証事項を追加した。未実行を成功扱いしない既存原則を、Parentの統合判断まで確実に伝えるため。
- 検証は変更に最も近いものから始め、影響範囲に応じて関連テストや型・Lint・build等へ広げる形にした。常時フルテストを避けつつ検証不足も防ぐ。

## 追加しなかったもの
新しいhandoff文書、固定テンプレート、SHA以外の状態管理、固定テスト一覧、特定AI向け手順は追加しない。
現在まだ実害が確認されていない問題を先回りして規則化しない。
