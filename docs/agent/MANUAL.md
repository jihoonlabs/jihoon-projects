# AGENTS review 候補報告

作成日: 2026-10-07

## 結論
v2の「少ないコンテキスト」「Child統合検証」「Git安全性」は維持しつつ、通常作業に不要なメタ規則と重複を削除した。AIが安全に自分で決められる範囲を明確にし、停止条件を契約変更・実質的scope変更・破壊的操作・製品判断へ絞った。

## 主な変更
- AGENTS改善サイクルをAGENTS本体から削除し、常時コンテキストを削減。
- 「必要なものだけ読む」を固定禁止ではなく段階的探索として明確化。
- 可逆な局所判断、既存方針内の修正、調査は質問せず自律進行。
- Child統合後の接続不具合は親作業が所有し、共有境界と親の完了条件を検証。
- テストは変更に近いものから段階的に広げ、全テストの機械的反復を避ける。
- WORKは今回の設計判断・比較根拠、MANUALはユーザー向け結論に限定し、AGENTSとの重複を減らした。

## 判断理由
このリポジトリでは複数のChildやLaravel/Reactの境界を統合するため、個別成功より接続点の整合性が重要。一方、AGENTSへ手順を増やすほど毎回のコンテキストと停止条件も増える。したがって「安全境界だけ固定し、その内側ではコードを調べて自律実行する」構成を優先した。

## 適用
このブランチは比較用候補。mainおよび `docs/agents-v2` は変更していない。最終採用は他候補との比較後に判断する。
