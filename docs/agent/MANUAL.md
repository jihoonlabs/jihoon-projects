# AGENTS v2 独立レビュー

更新日: 2026-10-07

## 結果
`docs/agents-v2`を基準に、ルール追加ではなく重複削減と判断境界の明確化を中心に候補を作成した。

主な変更:
- AIが止まる条件を、仕様決定・実質的な範囲拡大・破壊的操作・ユーザー意図が必要な選択へ限定した。
- Child分割は並列化の利益がある場合だけ行い、共有境界を変更したChildはproducer/consumer接続まで統合検証するよう明確化した。
- 「範囲外変更禁止」を緩め、変更によって直接壊れる利用側・テスト・文書の整合修正は同じ責任範囲として扱えるようにした。
- 検証は狭いテストから始め、最終的に変更範囲へ広げる方式へ整理した。
- AGENTSは恒久ルール、WORKは現在state、MANUALは結果報告に分離し、同じ運用方針の重複を削減した。
- AGENTS改善手順そのものを短縮し、通常作業のcontextを消費するメタルールを減らした。

## 判断理由
現在のv2は安全性の方向は適切だが、停止条件と変更境界が保守的すぎる部分があり、Child統合時の自律的な接続修正を妨げる可能性があった。最新のcoding-agent運用も、長い手順より短い恒久ルール、必要時の追加context、明確な境界と検証を重視する方向にあるため、この候補ではその原則を現在のEpic/Child運用へ合わせた。

## 検証
- 基準branch `docs/agents-v2`から独立review branchを作成。
- 変更対象は `AGENTS.md`、`docs/agent/WORK.md`、`docs/agent/MANUAL.md` のみ。
- Markdown内容、文書間の役割分離、最終diff、branch差分を確認。
- コード変更がないためアプリケーションテストは対象外。
