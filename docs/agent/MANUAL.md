# AGENTS v2 更新報告

更新候補作成日: 2026-10-07

## 目的
AGENTS.mdを増やすことではなく、AI作業の効率と安全性に必要な最小ルールを維持する。
公開AGENTSや最新トレンドは比較材料として使い、実作業に効果がない規則は追加しない。

## 今回の主な変更候補

### 1. 作業MDとMANUALを分離
- 作業MDはAI向け。目標、範囲、対象外、必要な文脈、完了条件、検証、現在状態を保持する。
- MANUALはユーザー向け報告。実際に追加・変更した機能、簡単な実装方法、テスト、影響、制約、main統合判断に必要な事実を説明する。

### 2. 分業後の統合を強化
Childを小さく分ける方針は維持するが、個別成功だけでは完了としない。
各Childの結果・境界・依存関係・前提を明確にし、統合前に整合性を確認する。
統合後はmerge成功だけでなく、API・データ・権限・状態・UI等の実際の接続点と親範囲の回帰を検証する。

### 3. コンテキスト制御を改善
開始時はAGENTS + 現在の作業MD + 必要なコードを基本とする。
ただし作業に直接必要なら関連コード・テスト・設定・文書を追加調査できる。
親・兄弟・過去MDを無条件に読むことはしない。

### 4. AGENTS改善サイクル
作業が一区切りした時だけ改善点を確認する。
改善点がなければAGENTS関連作業をスキップして次へ進む。
候補がある時は実作業の問題と最新の公式情報・公開事例を比較して報告する。
AGENTS本体はユーザー承認なしに変更しない。

## 適用方針
現在進行中のTicket作業には適用しない。
現在のTicketは開始時のルールで完了させる。
ユーザー承認後、次に新しく開始する作業・ブランチから適用する。
