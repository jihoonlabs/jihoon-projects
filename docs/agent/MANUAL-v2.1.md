# MANUALテンプレート v2.1

このファイルは、個別作業の完了を利用者へ報告するための記入形式です。作業AIは作業ごとに対象プロジェクトの所定の場所へコピーし、確認できた事実だけを記入します。

## 作業の目的

何を解決・実現する作業だったかを1〜2文で書く。

## 対応内容

- 変更したこと
- 変更した理由と、利用者から見える影響

## 確認結果

- 実行したテスト・検査と結果
- 手動確認の範囲
- 未実行の検証は「未検証」と明記する

## 制約・残課題

- 今回確認していない環境や条件
- 残っている作業、既知の制約
- 該当がなければ「なし」と書く

## 完了状態

未完了・完了・保留のいずれかと、その根拠を書く。必要ならブランチ、コミット、統合状態を記載する。

## 記入上の注意

- 作業指示や進捗管理にはWORKを使い、このMANUALを作業ログとして使わない。
- 実行していないテストや未確認の動作を、成功した事実として書かない。
- コードから明らかな説明を重ねず、利用者が結果と制約を判断する情報を優先する。
- 内部情報や公開範囲外の内容を含めない。
