# AGENTS v2.1 改訂結果

更新日: 2026-10-07

## 目的

実作業で得た知見をもとに、AI作業ルールの自律判断・作業分担・検証・統合の境界を整理した。

## 変更内容

- 既存コードや契約から安全に判断できる小さな実装判断は自律的に進め、結果を変える判断はユーザーに確認する。
- Parent/Childの責任と引き継ぎ情報を明確にし、統合後は接続点と親範囲の回帰も確認する。
- 変更に近い検証から始め、未実行の確認は未検証として扱う。
- 無関係なGit変更を保護しつつ、現在の作業と衝突する状態は報告する。
- AGENTSの改善提案を各作業に強制せず、根拠がある場合だけ見直す。

複数の独立レビューと実作業の知見を照合し、既存の基本構造を保てる範囲の変更をv2.1としてまとめた。

## 確認範囲と制約

この変更はエージェント向け文書のみを対象とし、Ticketアプリのコードやテストは変更していない。したがって、この改訂報告はアプリの動作検証を示すものではない。

このファイルと [WORK v2.1](WORK-v2.1.md) は公開ポートフォリオ用に整理した記録です。実運用の指示一式ではありません。ルール本文は [AGENTS v2.1](AGENTS-v2.1.md) を参照してください。
