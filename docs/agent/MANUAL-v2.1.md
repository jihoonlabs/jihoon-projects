# Ticketボード更新競合 — MANUAL例

## 目的

別の利用者が先にボードを更新したとき、古い画面からの移動で新しい並び順を上書きしないようにする。

## 変更内容

ボード移動時に画面側の `board_version` をサーバーの現在値と照合する。不一致ならHTTP 409で拒否し、チケットの状態を保持する。

## 実装の要点

ボード全体のバージョンを更新前提として使い、古い状態からの操作を検出する。競合後は最新のボードを再取得してから操作する。ボード単位で検出するため、同じボード上の別チケットの更新も競合対象になり得る。

## 検証根拠

[BoardOrderTest](../../laravel/tests/Feature/Ticket/BoardOrderTest.php) には、成功した移動でバージョンが進むことと、古いバージョンの移動が409になり、チケットとバージョンが変わらないことを確認するテストがある。[Ticketの検証記録](../ticket/TICKET.md)には、2026-10-27の公開デモ時点でReact 257 testsとLaravel全テストがGitHub Actionsを通過した記録がある。
