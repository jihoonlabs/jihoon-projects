# AGENTS v2.1 改訂報告

更新日: 2026-10-07

## 目的

実作業と複数の独立レビューで根拠が確認できた改善をまとめ、AGENTS v2の基本構造を保ったままv2.1として公開した。

## 実際に変えたこと

- **自律判断:** 既存コード・テスト・契約から安全に決められる小さな事項は進め、結果を変える判断に確認を絞った。
- **分割・統合:** Childの変更境界・依存・検証・未解決点と結果SHAをhandoffに含め、Parentが採用SHAと統合状態を持つ。
- **検証:** 変更に近い検証から始め、影響に応じて広げる。常時フルテストは求めない。
- **Git状態:** 無関係なdirty/untrackedを保護しながら、現在の責任と関係ない状態だけで作業全体を止めない。
- **規則の保守:** 各作業にAGENTS改善を強制せず、実作業で根拠が見つかった候補を扱う。
