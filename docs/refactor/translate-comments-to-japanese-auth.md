# Authコメント日本語化

## 目的
Laravel Auth領域の開発者向けコメントを、必要な箇所だけ自然な日本語へ整理する。

## 範囲
- Laravel Auth関連コードを対象とする。
- 英語コメントのうち、コードだけでは意図が明確でなく説明として残す価値があるものだけを日本語化する。
- 自明なコメントは増やさない。
- コードの動作、API契約、ユーザー向け文言、変数名・関数名・クラス名、テスト仕様は変更しない。

## 作業ルール
- `AGENTS.md` を最優先とし、このMDと必要な対象コードだけを通常コンテキストとして使う。
- 現在の責任に直接必要なファイルだけを変更する。
- 既存のdirty/untrackedファイル、他作業主体が変更中のファイルには触れない。
- 範囲外の修正が必要、または複数の妥当案・矛盾・不確実性を発見した場合は推測せず停止する。
- main、Ticket系、親 `refactor/translate-comments-to-japanese` へmergeしない。

## 検証
- 変更箇所に関連するLaravelテストを実行する。
- 必要なPHP syntax / Pint等の静的検証を行う。
- 最終diffでコメント以外の意図しない動作変更がないことを確認する。
- 未実行の検証は未検証として扱う。

## 完了条件
- 対象コメントの日本語化が完了している。
- 関連検証が成功している。
- 最終diffとgit statusを確認している。
- このブランチにcommitし、originへpushする。
- 完了後、このMDには再開に必要な最小限の現在状態だけを残す。
