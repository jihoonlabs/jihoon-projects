# Project leadership — handoff

Project leaders can hand their role to an existing member without changing either person's ticket read/write permission. Directly promoting a second leader or deleting the active leader is blocked.

Branch: `feature/ticket-project-leadership`. The work is committed to GitHub, **not merged**, and Laravel tests have **not been run** in this remote-only environment.

At home, run the project's existing Laravel tests and formatting checks, then review the handover API and the effects of simultaneous member changes. See `PROJECT_LEADERSHIP_WORK.md` for the contract and remaining concerns.
