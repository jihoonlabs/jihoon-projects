# ログイン画面の整理と動作修正

既存のカード・「タスク管理」「チケット管理」を保ち、操作を見つけやすく、誤送信とログイン状態の不整合を防ぐよう改善しました。

灰色のボタンはスタイル未指定が原因でした。既存CSS Moduleで一般/Google/LINEの高さ・角丸・文字・中央揃えを共通化し、一般ログインを青、Googleを白、LINEを淡い緑で区別しました。「または」とリンク/入力の間隔を整え、モバイルでは会員登録案内を折り返します。既存Lucideの目アイコンを入力内の右側に置き、入力の余白、type=button、表示/隠すの名前・押下状態とfocus表示を維持します。新しいロゴ・依存関係・過度なコンポーネント分割はありません。

同じrender内の重複submit、HTML/ネットワークエラーの生表示、不正な成功応答の認証状態への採用、遅延した初期セッション応答が新しいログインを取り消す不具合を修正しました。実ブラウザーで見つかった、古いSet-Cookieによる新セッションの上書きは、ログイン/ログアウト前の初期GET中断で防ぎます。失敗時の入力を保持し、CSRF・メール認証・停止ユーザーの拒否と既存のAPI/遷移を維持します。

共有Headerのログアウト失敗も成功として扱わず、状態保持と再試行案内に修正しました。Ticket画面にはこのHeaderが現在配置されていないため、新しいログアウトボタンは追加していません。共有UIは単体テスト、実セッション破棄はLaravel APIで確認しました。

React 180件、関連Laravel 32件（151 assertions）、型・Lint・Prettier・production buildが成功しました。隔離SQLite/設定で実Chromeの7シナリオを確認し、正常/失敗ログイン、Enter、重複防止・要求中表示、500/ネットワーク失敗、session/reload/logout、遅延応答、リンクとソーシャル開始を検証しました。デスクトップと375/320px幅のモバイルで横の切れ・横スクロール、アイコン/入力の重なりがないことを確認しています。

スクリーンショットと実行証跡は `/private/tmp/ticket-login-ui-check-20261012`、Child表示は `http://127.0.0.1:3240/login` です。既存Epic・環境設定・DBを変更せず、Childの一時DBだけに限定fixtureを作りました。

Google/LINEは実302の開始まで確認しました。外部認証の完了・隔離callbackの登録との整合は未検証です。MySQL同時実行も未検証。Childはローカル引き渡し準備済みで、Epic採用・pushは未実施です。詳細契約は [WORK](LOGIN_UI_WORK.md) にあります。
