# チケットボード

## ボードを開く

ログイン後にチケットボードを開き、プロジェクトを選択します。全プロジェクト表示では、アクセス可能なプロジェクトのチケットをまとめて確認できます。

## チケットを作成する

1. 編集権限のある稼働中プロジェクトを選びます。
2. 「チケット作成」を選び、タイトル、説明、ステータス、優先度、担当者を入力して保存します。
3. 担当者は、そのプロジェクトのメンバーから選びます。未割り当ても選べます。

## チケットを探す

- タイトルまたはチケットキーで検索します。
- 担当者フィルターで全員、自分、未割り当てを切り替えます。
- プロジェクトを選択すると、そのプロジェクトのチケットに絞り込まれます。

## チケットを更新・移動する

チケットを開くと、詳細を確認できます。編集権限があればタイトル、説明、ステータス、優先度、担当者を変更し、保存できます。カードは列間や列内でドラッグして移動できます。ステータスはチケット編集画面からも変更できます。

ステータスは「バックログ」「TODO」「進行中」「レビュー中」「完了」です。優先度は「最高」「高」「中」「低」「最低」です。

カードの並び順とステータス移動はサーバーに保存され、再読み込み後も反映されます。同時に別の変更が入った場合は、最新のボードを再取得してから操作してください。

## チケットを削除する

チケット詳細から「削除」を選び、確認します。削除したチケットはボードから取り除かれます。

閲覧権限または終了済みプロジェクトでは、チケットの作成・編集・移動・削除はできません。
