# チケットコメント

## コメントを読む・投稿する

1. ボード上のチケットを開きます。
2. 詳細画面の「コメント」欄で既存のコメントを読みます。
3. 入力欄にコメントを書き、「送信」を選びます。

コメントの投稿者はログイン中のユーザーとして記録されます。コメントが読み込めない場合は「コメントを再取得」を選びます。

## コメントを編集・削除する

- 投稿者は自分のコメントを編集できます。
- 投稿者は自分のコメントを削除できます。
- 管理者はコメントを削除できます。
- 閲覧のみの権限、または終了済みプロジェクトではコメントを変更できません。

コメントの編集・削除権限は画面だけでなくAPI側でも確認されます。
