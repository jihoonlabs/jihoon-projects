# チケットコメント

## コメントを読む・投稿する

1. ボード上のチケットを開きます。
2. 詳細画面の「コメント」欄で既存のコメントを読みます。
3. 入力欄にコメントを書き、「送信」を選びます。

コメントの投稿者はログイン中のユーザーとして記録されます。コメントが読み込めない場合は「コメントを再取得」を選びます。

対象プロジェクトのメンバーは、閲覧権限・編集権限のどちらでもコメントを閲覧・投稿できます。管理者も閲覧・投稿できます。プロジェクトに所属していない一般ユーザーは利用できません。

## コメントを編集・削除する

- 対象プロジェクトのメンバーである投稿者は、閲覧権限・編集権限のどちらでも自分のコメントを編集・削除できます。
- 他のメンバーのコメントは編集・削除できません。プロジェクトのリーダーも同じです。
- 管理者は他のユーザーのコメントを削除できますが、編集できるのは自分のコメントだけです。
- 終了済みプロジェクトでは閲覧のみ可能で、コメントの投稿・編集・削除はできません。

いずれの操作にもログインが必要です。利用停止中のユーザーはコメントを利用できません。

コメントの編集・削除権限は画面だけでなくAPI側でも確認されます。
