# プロジェクトとメンバー

Ticketは、チケットをプロジェクトごとに分けて管理します。

## プロジェクトを作成・選択する

1. チケットボードで「プロジェクト作成」または「一覧・作成」を開きます。
2. プロジェクト名を入力して作成します。作成者はそのプロジェクトのリーダーになります。
3. 一覧からプロジェクトを選ぶと、そのプロジェクトのボードが開きます。
4. 一覧ではプロジェクト名またはキーで検索できます。通常の一覧と終了済み一覧は切り替えられます。

「全プロジェクト」表示は閲覧用です。チケットを編集・移動する場合は対象プロジェクトを選択してください。

## メンバーと権限

リーダーまたは管理者は「メンバー」からプロジェクトメンバーを管理できます。

- メンバー追加には、すでに登録されているユーザーのメールアドレスを使います。
- 権限は「閲覧」または「編集」です。
- リーダーの引き継ぎ、メンバーの削除、権限変更を行えます。
- リーダーをメンバーから削除するには、先にリーダーを引き継ぎます。

閲覧権限ではチケットを確認できます。編集権限があるメンバーと管理者は、稼働中プロジェクトのチケットを作成・変更できます。

## プロジェクトを終了・復元する

1. すべてのチケットを「完了」にします。
2. プロジェクト設定から「プロジェクトを終了」を選び、確認します。
3. 終了済みプロジェクトは閲覧のみになり、チケットとコメントは保持されます。
4. 再開する場合は終了済み一覧から開き、「プロジェクトを復元」を選びます。

終了済みプロジェクトのチケットやメンバーを変更するには、先に復元してください。
