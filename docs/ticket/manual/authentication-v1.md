# アカウントとログイン

このページは、公開Ticket V1で確認できるアカウント操作を説明します。

## アカウントを作成する

1. `/register` を開きます。
2. 登録フォームに必要事項を入力して送信します。
3. 登録後、`/login` からログインします。

## ログインする

1. `/login` を開き、登録済みアカウントでログインします。
2. 認証後、チケットボードを利用します。
3. ログインしていない状態でボードを開くと、ログイン画面へ案内されます。

ログイン状態はLaravel Sanctumのセッションで管理されます。ブラウザーを再読み込みしても有効なセッションは確認されます。セッションが期限切れの場合は、画面に再ログインが表示されます。

## パスワードを再設定する

1. `/forgot-password` で登録メールアドレスを送信します。
2. メールに届く案内を開き、`/reset-password` で新しいパスワードを設定します。

## 関連機能

登録、ログイン、パスワード再設定などの画面とAPIは別々に実装されています。ログインできても、各プロジェクトへのアクセス権がなければそのプロジェクトの情報は利用できません。
