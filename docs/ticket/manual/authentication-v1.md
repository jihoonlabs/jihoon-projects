# アカウントとログイン

このページは、公開Ticket V1で確認できるアカウント操作を説明します。

## アカウントを作成する

1. `/register` を開きます。
2. 名前、メールアドレス、パスワード、確認用パスワードを入力し、「メールアドレスで登録」を選びます。パスワードは英字と数字を含む8文字以上で、確認用と一致する必要があります。
3. 登録に成功するとログイン画面に移動し、認証メールが送信されます。この時点ではログインしていません。
4. メール内の認証リンクを開きます。認証が完了するとログイン画面に戻ります。
5. `/login` から登録したメールアドレスとパスワードでログインします。メール認証が完了するまではログインできません。

未認証のためログインできない場合は、ログイン画面の「認証メールを再送する」から再送を要求できます。登録済みのメールアドレスは重複登録できません。入力エラーはフォームの案内に従って修正し、試行回数の制限が表示された場合は、しばらく待ってから再度操作してください。

## ログインする

1. `/login` を開き、登録済みアカウントでログインします。
2. 認証後、チケットボードを利用します。
3. ログインしていない状態でボードを開くと、ログイン画面へ案内されます。

ログイン状態はLaravel Sanctumのセッションで管理されます。ブラウザーを再読み込みしても有効なセッションは確認されます。セッションが期限切れの場合は、画面に再ログインが表示されます。

## パスワードを再設定する

1. `/forgot-password` で登録メールアドレスを送信します。
2. メールに届く案内を開き、`/reset-password` で新しいパスワードを設定します。

## 関連機能

登録、ログイン、パスワード再設定などの画面とAPIは別々に実装されています。ログインできても、各プロジェクトへのアクセス権がなければそのプロジェクトの情報は利用できません。
