# 勤怠機能 操作ガイド

## 機能概要

ログイン後に勤怠画面を表示します。今日の状態と時刻を確認して出勤・退勤を記録でき、画面下部では自分の過去の記録と勤務時間を確認できます。サイドバーからTicketにも移動できます。

## 出勤・退勤

- 出勤前は「出勤」ボタンが有効です。記録すると当日の出勤時刻が表示され、状態が「勤務中」になります。
- 勤務中は「退勤」ボタンが有効です。記録すると退勤時刻と勤務時間が表示され、状態が「退勤済み」になります。
- 勤務時間は退勤時刻から出勤時刻を差し引いて計算します。休憩時間は差し引きません。
- 日付は日本時間を基準にします。日付をまたいで退勤した場合も、記録は元の出勤日に紐づきます。
- 同じ日の重複出勤、出勤前の退勤、退勤後の再退勤はできません。

## 勤怠履歴

「自分の勤怠記録」に勤務日、出勤時刻、退勤時刻、勤務時間が表示されます。記録はログイン中の利用者に紐づき、1ページあたり30件を表示します。複数ページある場合は「前へ」「次へ」で移動できます。

## ローカルで動作を確認する場合

Laravel APIとReactアプリをそれぞれ起動します。初回はLaravelの`.env`設定とデータベースマイグレーションが必要です。既存データベースを削除する必要はありません。

APIのURLや起動方法は [Laravel API README](../../laravel/README.md)、React側は [React README](../../react/README.md) を参照してください。
