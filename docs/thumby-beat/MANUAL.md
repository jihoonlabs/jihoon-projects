# Thumby Beat — 公開マニュアル

## ゲームについて

白黒 Thumby（72×40）向けの小さなリズムゲームです。携帯ゲーム機の音楽ゲームを参考に、Thumby のボタン数と単音ブザーに合わせて独自に作り直しました。上から落ちてくるノートが判定ラインに重なった瞬間に、対応するボタンを押します。

- ブザーは単音のため、昔の携帯電話の着信メロディのような音になります。
- ノートを押すとその音が鳴る「キー音」方式です。キー音のない間は、伴奏が自動で鳴ります。
- 譜面に同時押しはありません。A+B の同時押しはスタート操作に使います。
- 画面右側では、リズムに合わせて小さなキャラクターが踊ります。

## Thumbyで実行する

`ThumbyBeat.py`、`rules.py`、`charts.py`、`pat.py` と曲ファイル `s_*.py`（20個）を同じゲームフォルダー（`/Games/ThumbyBeat`）へコピーし、`ThumbyBeat.py` を実行します。曲ファイルは選んだ曲だけを読み込むため、20曲すべてを同時にメモリーへ置くことはありません。保存領域の名前は `ThumbyBeat` です。

配布ZIPを作成する場合:

```bash
python3 micropython/Thumby/ThumbyBeat/tools/package_game.py --output /tmp/ThumbyBeat.zip
```

## 操作

| 画面 | 操作 |
| --- | --- |
| タイトル | A+B（または A）でスタート。しばらく操作しないとデモ演奏が始まり、どのボタンでもタイトルへ戻ります |
| モード選択 | 上下で GAME / AUTO PLAY を選び、A（または A+B）で決定、B でタイトルへ |
| 曲選択 | 上下で曲を選択、左右でノートの速さ（SPD1〜5）、A で開始、B でモード選択へ |
| プレイ | 上または下＝スクラッチ（左端の太いレーン）、左・右・B・A＝4つのキー |
| プレイ中の一時停止 | A+B を約0.3秒押し続けます。上下で CONTINUE / RETRY / QUIT を選び A で決定、B で再開 |
| リザルト | A または B で曲選択へ |

レーンは左から「スクラッチ・左・右・B・A」の順です。

AUTO PLAY では、選んだ曲をゲームが自動で演奏します。手本として譜面と音を確認するためのモードで、結果は表示しますがハイスコアやランプは保存しません。演奏中も A+B の長押しで一時停止できます。

## 判定とスコア

- 判定: GREAT（±50ms）、GOOD（±100ms）、BAD（±150ms）。押さずに通過したノートは POOR です。
- EXスコア: GREAT＝2点、GOOD＝1点。最大はノート数×2です。
- コンボ: GREAT と GOOD でつながり、BAD と POOR で途切れます。
- ゲージ: 22%から始まり、曲の最後に80%以上ならクリアです。ゲージが減っても曲の途中では終了しません。
- ランク: EXスコアの割合で AAA〜F を表示します。
- ランプ: FAILED / CLEAR / FULL COMBO（BAD と POOR なし）。
- 曲ごとのハイスコアとランプ、ノートの速さを保存します。保存は曲選択とリザルトの画面でのみ行い、プレイ中には書き込みません。

## テストと確認範囲

PC上のゲームロジック・画面描画・入力・保存・配布ZIPのテストは次のコマンドで実行できます。

```bash
python3 -m unittest discover -s micropython/Thumby/ThumbyBeat -p 'test_*.py' -v
```

2026-11-09時点で、Python 3.13 上のテスト62件が通過しました。テストでは本物の `thumby` モジュールの代わりに `fake_thumby.py`（72×40の画素バッファーを持つ代替品）を使い、全20曲の自動演奏、画面外への描画がないこと、譜面に同時押しがないこと、伴奏と譜面の小節数が一致することを確認しています。

次の項目はまだ確認していません。

- Thumby 実機またはエミュレーターでの動作
- MicroPython でのコンパイルと実行速度、メモリ使用量（曲ファイルの読み込み時間を含む）
- ブザーの音質、キー音と伴奏の聞こえ方、ボタンの押しやすさ
- `fake_thumby.py` の文字描画は外形のみで、実機のフォントとは異なります
