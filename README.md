# jihoon-projects
Personal projects (Vue, React, ETC)

## Ticket管理ボード

Laravel API と React を連携した、Jira 形式のチケットボードです。Laravel Sanctum のセッション認証を利用し、チケットの一覧・作成・編集・削除、ステータス変更、検索、担当者フィルター、ドラッグ＆ドロップによる移動に対応しています。チケットへのコメントも作成・編集・削除できます。

API の snake_case 応答は React の画面モデルへ変換します。コメントの投稿者はログインユーザーから決定し、編集・削除権限は API 側で検証します。カードの並び順はクライアント側で管理し、データベースには保存しません。担当者の全ユーザー検索と管理者機能は含みません。
