# MicroPython Brawler 개발 에이전트 공통 규칙 (AGENTS.md)

## 📌 1. 브랜치 & 작업 원칙
* **베이스 브랜치**: `feature/brawler`
* **원칙**: 베이스 브랜치는 가급적 소스 코드를 직접 수정하지 않고 안정 상태로 보존합니다.
* **하위 브랜치 체계**: 모든 작업은 `feature/brawler-<기능명>` 형태로 하위 브랜치를 파서 독립 진행합니다.
* **컨텍스트 최적화**: 
  - 각 하위 브랜치 작업 시 **`AGENTS.md`(공통 규칙)** + **`TASK_<기능명>.md`(하위 브랜치 규칙)** 2개 문서만 참조합니다.
  - 불필요한 전체 코드 컨텍스트 로딩을 방지하여 토큰 소비를 대폭 줄이고 퀄리티를 극대화합니다.

---

## 🛠️ 2. MicroPython 코딩 & 임베디드 핵심 규칙

1. **MicroPython 30 FPS GC(가비지 컬렉터) 보존**:
   * `main.py`나 메인 루프(`update`, `draw`) 안에서 매 프레임 객체를 동적 생성(`new`)하지 않습니다.
   * 히트박스, 리스트, 임시 객체 등은 맴버 변수 선언 시 사전 할당(Object Pooling / Static Reference)하여 사용합니다.

2. **버튼 입력 버퍼(Input Buffer) 보존**:
   * 소형 기기 버튼 특성상 `A+B` 동시 입력 판정 시 최소 2~3프레임 윈도우 버퍼를 두어 입력 씹힘을 방지합니다.

3. **3D 볼륨 히트박스 판정 정밀화**:
   * `X`(전방거리), `Y`(레인 깊이), `Z`(점프 높이) 3축 판정 시 사거리 오프셋 중복 계산이 없도록 픽셀 영역을 정확히 래핑합니다.
