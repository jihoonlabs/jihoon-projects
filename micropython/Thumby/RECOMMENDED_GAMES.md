# Thumby 추천 게임 후보 및 기술 검증 백로그

> 상태: 아이디어/추천 목록. 기존 확정 개발 목표를 변경하거나 자동 착수하지 않는다.
> 대상: Original Thumby (72×40, 1-bit), Thumby Color (128×128, color).

## 목표 및 원칙
- 단순 미니게임이 아닌 원작의 핵심 게임 루프와 깊이를 유지하는 소형 게임.
- 디스플레이의 픽셀을 최대한 활용하되, 가독성·프레임·입력 반응을 우선한다.
- 기종별 렌더러/UI는 별도로 최적화하고 게임 규칙·데이터·테스트 자산을 가능한 범위에서 공유한다.
- 기존 확정 목표: 슈퍼로봇대전, 건담 제네레이션, 악마성 효월의 원무곡, 쿠니오군 시대극, 베어너클, KOF, 비트매니아. 본 문서는 이들을 대체하지 않는다.
- 원작의 에셋·상표·시나리오를 그대로 복제하기보다는 시스템을 참고한 독자 작품 제작을 우선한다.

## 평가 해석
- 적합도 M/C: Original/Color 각 5점 만점의 설계 추정.
- 보존율: 핵심 시스템을 축소 재구현할 때의 가설적 비율(원작 전체 콘텐츠 재현율이 아님).
- 기간: 공통 엔진/도구가 준비된 1인 개발자, 하루 약 6시간 기준의 매우 거친 추정. 실기 검증 전에는 확정 일정으로 사용하지 않는다.
- 병목: 실제 프로파일링으로 재평가해야 한다.

## 별도 우선 추천 (기존 목표와 구분)
1. 풍래의 시렌: 랜덤 던전·턴제 AI·아이템·상태이상·저장, 로그라이크 엔진의 장기 기준작.
2. 메달롯: 부위별 파츠와 성장, 로봇 전투 데이터 구조 재사용.
3. 프론트 미션: SRPG 엔진을 파츠 파괴/장착으로 확장.
4. Cave Noire: 오리지널 Thumby의 가독성·타일 렌더링 검증.
5. 가고일즈 퀘스트: 스크롤/애니메이션/충돌 최적화 검증.
6. 카드 히어로: 카드 데이터와 AI.
7. 포켓몬 불가사의 던전: 동료 AI 포함 로그라이크 확장.
8. 메트로이드 II: 맵·카메라·실시간 액션 성능 검증.

## 공통 엔진 후보
- SRPG: 로봇대전/건담 제네레이션/프론트 미션/샤이닝 포스.
- 로그라이크: 풍래의 시렌/토르네코/Cave Noire/포켓몬 불가사의 던전.
- RPG·육성: 메달롯/여신전생/몬스터 수집·성장.
- 액션: 가고일즈 퀘스트/메트로이드 II/악마성/쿠니오군.
- 카드·경영: 카드 히어로/게임 개발국/심시티.
- 공통 코어는 게임 규칙, 데이터 포맷, 저장 스키마, 결정적 테스트 위주. 디스플레이·입력·사운드 API는 기종별 어댑터.

## 착수 전 검증 게이트
1. Original 72×40 1-bit / Color 128×128에서 타일 크기(6/8/16px), UI, 캐릭터 가독성 실기 확인.
2. 프레임 시간, 렌더/화면 전송 비용, 힙 여유, 최대 스프라이트/타일/맵 크기 측정.
3. 입력 수와 메뉴 조작 피로도 검증; 저장/로드, 일시정지, 재시작 테스트.
4. 게임별 원작 핵심 루프를 정의하고 최소 콘텐츠·확장 콘텐츠를 분리.
5. 성능 검증 뒤 우선순위와 일정 재산정. 추천 목록을 확정 개발 약속으로 간주하지 않는다.
