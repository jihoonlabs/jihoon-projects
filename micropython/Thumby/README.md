# Thumby

一般的な白黒 Thumby 向けゲームをゲーム別フォルダーに置いています。

- `ThumbyBrawlBase/`: エージェント用Markdownの作業基準を適用しながら開発しているゲームベース
- `ThumbyBeat/`: スクラッチと4キーで遊ぶ小さなリズムゲーム（[マニュアル](../../docs/thumby-beat/MANUAL.md)）
- [既存の格闘ゲーム](../ThumbyFight/): 現行リポジトリの旧配置にある ThumbyFight

ゲームの概要、操作、テスト方法は各フォルダーのREADMEを参照してください。保存・実行時のフォルダー名はゲームごとに異なります。
