ThumbyGrowth — 5전투 액션 RPG / 첫 플레이용 버전

목표: 전투 5회를 이겨 마지막 보스를 쓰러뜨리면 QUEST CLEAR.
기기: 일반 흑백 Thumby 72×40. Thumby Color용이 아닙니다.

설치:
1. ZIP을 풀고 ThumbyGrowth.py와 rules.py 두 파일을 함께 준비합니다.
2. 기기 또는 에뮬레이터의 /Games/ThumbyGrowth/에 두 파일을 넣습니다.
3. ThumbyGrowth.py를 실행합니다. README와 BUILD.json은 기기에 넣지 않아도 됩니다.

시작:
타이틀에서 A: 새 게임 / B: 저장 불러오기.
새 게임을 눌러도 기존 저장은 자동으로 덮어쓰지 않습니다.
저장은 메뉴에서 직접 실행합니다. 저장이 없으면 새 게임으로 시작합니다.

조작:
전투: 방향키를 누르는 동안 상하좌우 이동, A 공격, B 일시정지.
메뉴: 위/아래로 선택, A 실행, B 복귀.
상점/장비: 목록에서도 A 구매/장착 가능. 오른쪽으로 상세 확인.
안전 지역: NEXT 전투 / SHOP 구매 / EQUIP 장착 / SAVE 저장.
패배: A로 현재 스테이지 재도전. 돈·장비·진행은 유지됩니다.
엔딩: A로 새 게임 / B로 클리어 상태 저장.

플레이 힌트:
적과 같은 높이에서 바라보는 방향으로 공격하세요.
위아래로 피하거나 거리를 벌리며 공격 재사용 시간을 기다릴 수 있습니다.
구매만으로 능력치가 오르지 않습니다. EQUIP에서 장착하세요.
전투 승리 후 체력이 회복됩니다. 두 전투를 이기면 기본 무기를 살 수 있습니다.
5번째 전투는 보스이며 체력·공격·방어가 더 높습니다.

검증:
CPython 게임 검사 51개 통과.
실제 입력 흐름으로 5전투, 구매, 장착, 저장·복원, 엔딩, 새 게임을 확인했습니다.
실제 Thumby/에뮬레이터의 속도·메모리·조작감 확인은 남아 있습니다.
이번 마무리 코드는 ChatGPT에서 작성했습니다. Ollama 생성 완료로 표현하지 않습니다.
기존 version=1 저장 형식과 저장 이름 ThumbyGrowth를 유지합니다.
